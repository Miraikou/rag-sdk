# 生成模块

生成模块是 RAG 系统的最终环节，负责将检索到的内容与用户问题一起组装成 prompt，调用 LLM 生成最终回答，并对回答质量进行保障和评估。

---

## 1. PromptTemplate（提示词模板）

### 概念说明

将检索到的文档内容和用户问题按照固定格式组装成 prompt，送入 LLM 生成回答。提示词模板决定了 LLM 如何理解任务、如何使用提供的上下文。

### 解决的问题

- 统一的 prompt 格式管理，避免各处拼接逻辑不一致
- 内置经过验证的最佳实践模板，减少 prompt 工程成本
- 支持变量插值，灵活适配不同场景

### TypeScript 类定义

```typescript
/** 消息角色 */
type MessageRole = "system" | "user" | "assistant";

/** LLM 消息格式 */
interface Message {
  role: MessageRole;
  content: string;
}

/** 模板变量 */
interface TemplateVariables {
  /** 用户查询 */
  query: string;
  /** 检索到的上下文内容 */
  context: string;
  /** 来源信息 */
  sources?: string;
  /** 其他自定义变量 */
  [key: string]: string | undefined;
}

/** 模板格式化选项 */
interface FormatOptions {
  /** 自定义系统消息 */
  systemMessage?: string;
  /** 最大上下文 token 数 */
  maxContextTokens?: number;
  /** 来源标注格式 */
  citationFormat?: "numbered" | "named" | "none";
}

/** 模板接口 */
interface PromptTemplate {
  /**
   * 将查询和上下文格式化为 LLM 消息
   * @param query - 用户查询
   * @param chunks - 检索到的文档片段
   * @param options - 格式化选项
   * @returns 格式化的消息列表
   */
  format(
    query: string,
    chunks: SearchResult[],
    options?: FormatOptions
  ): Message[];
}

/** 基础模板实现 */
class BasePromptTemplate implements PromptTemplate {
  private systemTemplate: string;
  private userTemplate: string;

  constructor(systemTemplate: string, userTemplate: string) {
    this.systemTemplate = systemTemplate;
    this.userTemplate = userTemplate;
  }

  format(
    query: string,
    chunks: SearchResult[],
    options?: FormatOptions
  ): Message[] {
    const context = chunks
      .map((chunk, index) => `[来源${index + 1}] ${chunk.content}`)
      .join("\n\n");

    const sources = chunks
      .map((chunk, index) => `[来源${index + 1}] ${chunk.metadata["title"] ?? "未知来源"}`)
      .join("\n");

    const variables: TemplateVariables = {
      query,
      context,
      sources,
    };

    const systemContent = this.interpolate(this.systemTemplate, variables);
    const userContent = this.interpolate(this.userTemplate, variables);

    return [
      { role: "system", content: systemContent },
      { role: "user", content: userContent },
    ];
  }

  private interpolate(template: string, variables: TemplateVariables): string {
    return template.replace(/\{(\w+)\}/g, (match, key) => {
      return variables[key] ?? match;
    });
  }
}
```

### 内置预设模板

```typescript
/** 基础问答模板 */
const DefaultTemplate = new BasePromptTemplate(
  `你是一个知识渊博的助手。请根据以下参考资料回答用户的问题。
如果参考资料中没有相关信息，请如实告知。

参考资料：
{context}`,
  `问题：{query}

请根据上述参考资料给出详细回答。`
);

/** 严格模式模板：限制只使用提供的内容 */
const StrictTemplate = new BasePromptTemplate(
  `你是一个严格的问答助手。你必须只根据提供的参考资料回答问题。
规则：
1. 只能使用参考资料中的信息
2. 如果资料中没有答案，回答"根据提供的资料无法回答此问题"
3. 不要添加任何资料中没有的信息
4. 不要使用你的训练知识补充

参考资料：
{context}`,
  `问题：{query}

请严格基于上述参考资料回答。如果资料不足以回答，请明确说明。`
);

/** 引用模板：要求标注信息来源 */
const CitationTemplate = new BasePromptTemplate(
  `你是一个严谨的研究助手。请根据参考资料回答问题，并在回答中标注每句话的来源。
规则：
1. 每个事实性陈述后标注来源编号，如 [来源1]
2. 如果多个来源支持同一观点，标注所有相关来源
3. 在回答末尾列出所有引用的来源

来源列表：
{sources}

参考资料：
{context}`,
  `问题：{query}

请给出带引用标注的回答，并在末尾列出所有引用的来源。`
);
```

### 关键参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `systemTemplate` | `string` | 系统消息模板，支持 `{query}`、`{context}`、`{sources}` 变量 |
| `userTemplate` | `string` | 用户消息模板 |
| `maxContextTokens` | `number` | 上下文最大 token 数限制 |
| `citationFormat` | `"numbered" \| "named" \| "none"` | 引用标注格式 |

### 使用示例

```typescript
// 使用默认模板
const messages = DefaultTemplate.format("什么是微服务", searchResults);
const answer = await llmProvider.chat(messages);

// 使用严格模式
const strictMessages = StrictTemplate.format("公司Q3营收", searchResults);

// 自定义模板
const customTemplate = new BasePromptTemplate(
  `你是技术支持助手。
参考资料：{context}`,
  `用户问题：{query}
请用简洁的步骤回答，每步不超过两句话。`
);
const customMessages = customTemplate.format("如何重置密码", searchResults);
```

## 2. Generator（答案生成器）

### 概念说明

调用 LLM 基于检索结果生成最终回答。Generator 是 RAG 管道的核心组件，将 PromptTemplate 组装好的 prompt 送入 LLM，获取结构化的生成结果。

### 解决的问题

- 统一管理 LLM 调用逻辑
- 支持同步和流式两种生成模式
- 封装生成结果的结构化处理

### TypeScript 类定义

```typescript
/** 生成结果 */
interface GenerateResult {
  /** 生成的回答文本 */
  answer: string;
  /** 来源信息 */
  sources: Array<{
    id: string;
    content: string;
    metadata: Record<string, unknown>;
  }>;
  /** token 使用统计 */
  usage?: {
    promptTokens: number;
    completionTokens: number;
    totalTokens: number;
  };
  /** 额外元数据 */
  metadata: Record<string, unknown>;
}

/** 生成选项 */
interface GenerateOptions {
  /** 模型名称 */
  model?: string;
  /** 生成温度 */
  temperature?: number;
  /** 最大 token 数 */
  maxTokens?: number;
  /** 是否返回 token 统计 */
  includeUsage?: boolean;
}

/** 生成器接口 */
interface Generator {
  /**
   * 生成回答
   * @param query - 用户查询
   * @param chunks - 检索到的文档片段
   * @param options - 生成选项
   * @returns 生成结果
   */
  generate(
    query: string,
    chunks: SearchResult[],
    options?: GenerateOptions
  ): Promise<GenerateResult>;

  /**
   * 流式生成回答
   * @param query - 用户查询
   * @param chunks - 检索到的文档片段
   * @returns 流式文本块
   */
  generateStream(
    query: string,
    chunks: SearchResult[]
  ): AsyncIterable<string>;
}

/** 基础生成器实现 */
class BaseGenerator implements Generator {
  private llmProvider: LLMProvider;
  private template: PromptTemplate;

  constructor(llmProvider: LLMProvider, template?: PromptTemplate) {
    this.llmProvider = llmProvider;
    this.template = template ?? DefaultTemplate;
  }

  async generate(
    query: string,
    chunks: SearchResult[],
    options?: GenerateOptions
  ): Promise<GenerateResult> {
    // 1. 组装 prompt
    const messages = this.template.format(query, chunks);

    // 2. 调用 LLM
    const response = await this.llmProvider.chat(messages, {
      model: options?.model,
      temperature: options?.temperature ?? 0.3,
      maxTokens: options?.maxTokens,
    });

    // 3. 组装结构化结果
    return {
      answer: response.content,
      sources: chunks.map((chunk) => ({
        id: chunk.id,
        content: chunk.content,
        metadata: chunk.metadata,
      })),
      usage: response.usage,
      metadata: {
        model: options?.model ?? "default",
        chunkCount: chunks.length,
      },
    };
  }

  async *generateStream(
    query: string,
    chunks: SearchResult[]
  ): AsyncIterable<string> {
    const messages = this.template.format(query, chunks);

    for await (const chunk of this.llmProvider.chatStream(messages)) {
      yield chunk.content;
    }
  }
}
```

### 关键参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `model` | `string` | 由 LLMProvider 决定 | 使用的模型名称 |
| `temperature` | `number` | `0.3` | 生成温度，越低越确定性 |
| `maxTokens` | `number` | 由 LLMProvider 决定 | 最大生成 token 数 |
| `includeUsage` | `boolean` | `false` | 是否返回 token 统计 |

### 使用示例

```typescript
// 基础使用
const generator = new BaseGenerator(llmProvider, DefaultTemplate);

const result = await generator.generate(
  "如何部署 Kubernetes",
  searchResults,
  { temperature: 0.2, maxTokens: 2000 }
);
console.log(result.answer);
console.log(`使用了 ${result.usage?.totalTokens} tokens`);

// 流式生成
const stream = generator.generateStream("解释微服务架构", searchResults);
for await (const textChunk of stream) {
  process.stdout.write(textChunk); // 实时输出
}
```

## 3. Grounding（接地/归因）

### 概念说明

确保 LLM 的回答完全基于检索到的内容，防止 LLM 编造不存在的信息（即"幻觉"问题）。Grounding 通过两个层面实现：生成时（prompt 约束）和生成后（验证检查）。

### 解决的问题

- LLM 可能会"自信地编造"不存在的事实
- 用户难以区分哪些内容来自检索资料、哪些是 LLM 自行生成的
- 在专业领域（法律、医疗、金融），幻觉可能导致严重后果

### TypeScript 类定义

```typescript
/** 验证结果 */
interface GroundingVerification {
  /** 是否通过接地验证 */
  grounded: boolean;
  /** 每句话的验证详情 */
  claims: Array<{
    /** 原文中的陈述 */
    claim: string;
    /** 是否有资料支撑 */
    supported: boolean;
    /** 支撑来源（如果有） */
    sourceSnippet?: string;
    /** 置信度 */
    confidence: number;
  }>;
  /** 未找到支撑的陈述数量 */
  unsupportedCount: number;
  /** 总陈述数量 */
  totalClaims: number;
}

/** 带接地的生成结果 */
interface GroundedGenerateResult extends GenerateResult {
  /** 接地验证结果 */
  verification: GroundingVerification;
}

class GroundedGenerator {
  private generator: Generator;
  private llmProvider: LLMProvider;
  private template: PromptTemplate;
  private verificationThreshold: number;

  constructor(
    generator: Generator,
    llmProvider: LLMProvider,
    options?: {
      /** 验证严格程度：0-1，越高越严格 */
      verificationThreshold?: number;
      /** 使用严格模板 */
      useStrictTemplate?: boolean;
    }
  ) {
    this.generator = generator;
    this.llmProvider = llmProvider;
    this.template = options?.useStrictTemplate
      ? StrictTemplate
      : DefaultTemplate;
    this.verificationThreshold = options?.verificationThreshold ?? 0.7;
  }

  /**
   * 生成带接地验证的回答
   * @param query - 用户查询
   * @param chunks - 检索到的文档片段
   * @param options - 生成选项
   * @returns 带验证信息的生成结果
   */
  async generate(
    query: string,
    chunks: SearchResult[],
    options?: GenerateOptions
  ): Promise<GroundedGenerateResult> {
    // 1. 使用严格模板生成回答
    const messages = this.template.format(query, chunks);
    const response = await this.llmProvider.chat(messages, {
      model: options?.model,
      temperature: 0.2, // 低温度减少幻觉
    });

    // 2. 生成后验证：检查每句话是否有资料支撑
    const verification = await this.verifyGrounding(
      response.content,
      chunks,
      query
    );

    // 3. 组装结果
    return {
      answer: response.content,
      sources: chunks.map((chunk) => ({
        id: chunk.id,
        content: chunk.content,
        metadata: chunk.metadata,
      })),
      usage: response.usage,
      metadata: {
        grounded: verification.grounded,
        verificationThreshold: this.verificationThreshold,
      },
      verification,
    };
  }

  private async verifyGrounding(
    answer: string,
    chunks: SearchResult[],
    query: string
  ): Promise<GroundingVerification> {
    const context = chunks.map((c) => c.content).join("\n\n");

    const response = await this.llmProvider.chat([
      {
        role: "system",
        content: `你是一个事实核查助手。请分析以下回答中的每个陈述，判断它是否有参考资料支撑。

参考资料：
${context}

回答：
${answer}

请逐条分析，输出 JSON 格式：
{
  "claims": [
    { "claim": "陈述内容", "supported": true/false, "confidence": 0.0-1.0 }
  ]
}`,
      },
    ]);

    const parsed = JSON.parse(response.content) as { claims: Array<{
      claim: string;
      supported: boolean;
      confidence: number;
    }> };

    const unsupportedCount = parsed.claims.filter((c) => !c.supported).length;
    const groundedRatio =
      (parsed.claims.length - unsupportedCount) / parsed.claims.length;

    return {
      grounded: groundedRatio >= this.verificationThreshold,
      claims: parsed.claims.map((c) => ({
        ...c,
        sourceSnippet: undefined,
      })),
      unsupportedCount,
      totalClaims: parsed.claims.length,
    };
  }
}
```

### 关键参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `verificationThreshold` | `number` | `0.7` | 验证通过所需的接地比例 |
| `useStrictTemplate` | `boolean` | `false` | 是否使用严格模板 |

### 使用示例

```typescript
const groundedGenerator = new GroundedGenerator(baseGenerator, llmProvider, {
  verificationThreshold: 0.8,
  useStrictTemplate: true,
});

const result = await groundedGenerator.generate(
  "公司2024年Q3的营收是多少",
  searchResults
);

console.log(result.answer);
console.log(`接地验证: ${result.verification.grounded ? "通过" : "未通过"}`);
console.log(
  `支撑率: ${result.verification.totalClaims - result.verification.unsupportedCount}/${result.verification.totalClaims}`
);

// 查看未被支撑的陈述
const unsupported = result.verification.claims.filter((c) => !c.supported);
for (const claim of unsupported) {
  console.log(`⚠️ 未找到支撑: "${claim.claim}" (置信度: ${claim.confidence})`);
}
```

## 4. CitationGenerator（带引用的回答）

### 概念说明

在生成的回答中标注每句话来自哪个文档或片段，让用户可以追溯信息来源。引用以 `[来源1]`、`[来源2]` 的形式嵌入回答文本，并在末尾附上完整的来源列表。

### 解决的问题

- 用户无法判断回答中的信息是否可靠
- 无法追溯某个说法的具体出处
- 在学术、法律、企业知识库等场景中，引用是基本要求

### TypeScript 类定义

```typescript
/** 引用信息 */
interface Citation {
  /** 引用编号 */
  index: number;
  /** 来源文档 ID */
  sourceId: string;
  /** 来源标题 */
  title: string;
  /** 匹配的原文片段 */
  snippet: string;
  /** 相关性分数 */
  relevanceScore: number;
  /** 来源元数据 */
  metadata: Record<string, unknown>;
}

/** 带引用的生成结果 */
interface CitationGenerateResult extends GenerateResult {
  /** 详细引用信息列表 */
  citations: Citation[];
  /** 带引用标记的回答文本 */
  citedAnswer: string;
  /** 来源列表（格式化输出） */
  sourceList: string;
}

class CitationGenerator {
  private llmProvider: LLMProvider;
  private template: PromptTemplate;

  constructor(llmProvider: LLMProvider, template?: PromptTemplate) {
    this.llmProvider = llmProvider;
    this.template = template ?? CitationTemplate;
  }

  /**
   * 生成带引用的回答
   * @param query - 用户查询
   * @param chunks - 检索到的文档片段
   * @param options - 生成选项
   * @returns 带引用的生成结果
   */
  async generate(
    query: string,
    chunks: SearchResult[],
    options?: GenerateOptions
  ): Promise<CitationGenerateResult> {
    // 1. 使用引用模板生成初始回答
    const messages = this.template.format(query, chunks);
    const response = await this.llmProvider.chat(messages, {
      model: options?.model,
      temperature: options?.temperature ?? 0.3,
    });

    // 2. 解析和规范化引用标记
    const { citedAnswer, citations } = this.parseCitations(
      response.content,
      chunks
    );

    // 3. 生成来源列表
    const sourceList = this.formatSourceList(citations);

    return {
      answer: response.content,
      citedAnswer,
      citations,
      sourceList,
      sources: chunks.map((chunk) => ({
        id: chunk.id,
        content: chunk.content,
        metadata: chunk.metadata,
      })),
      usage: response.usage,
      metadata: {
        citationCount: citations.length,
      },
    };
  }

  private parseCitations(
    answer: string,
    chunks: SearchResult[]
  ): { citedAnswer: string; citations: Citation[] } {
    const citations: Citation[] = [];
    const citationRegex = /\[来源(\d+)\]/g;
    const matchedIndices = new Set<number>();

    let match: RegExpExecArray | null;
    while ((match = citationRegex.exec(answer)) !== null) {
      const index = parseInt(match[1], 10);
      if (index >= 1 && index <= chunks.length) {
        matchedIndices.add(index);
      }
    }

    // 构建引用信息
    for (const index of Array.from(matchedIndices).sort((a, b) => a - b)) {
      const chunk = chunks[index - 1];
      citations.push({
        index,
        sourceId: chunk.id,
        title: (chunk.metadata["title"] as string) ?? "未知来源",
        snippet: chunk.content.slice(0, 200),
        relevanceScore: chunk.score,
        metadata: chunk.metadata,
      });
    }

    return { citedAnswer: answer, citations };
  }

  private formatSourceList(citations: Citation[]): string {
    return citations
      .map(
        (c) =>
          `[来源${c.index}] ${c.title} (相关度: ${c.relevanceScore.toFixed(2)})`
      )
      .join("\n");
  }
}
```

### 关键参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `template` | `PromptTemplate` | 使用的提示词模板，默认 CitationTemplate |
| `model` | `string` | 使用的 LLM 模型 |
| `temperature` | `number` | 生成温度 |

### 使用示例

```typescript
const citationGen = new CitationGenerator(llmProvider);

const result = await citationGen.generate(
  "Kubernetes 和 Docker 的区别是什么",
  searchResults,
  { model: "gpt-4o" }
);

// 输出带引用的回答
console.log(result.citedAnswer);
// "Kubernetes 是容器编排平台 [来源1]，而 Docker 是容器运行时 [来源2]。
//  Kubernetes 可以管理多个 Docker 容器 [来源3]..."

// 输出来源列表
console.log(result.sourceList);
// [来源1] K8s官方文档 (相关度: 0.92)
// [来源2] Docker概述 (相关度: 0.89)
// [来源3] K8s vs Docker对比 (相关度: 0.85)

// 访问详细引用信息
for (const citation of result.citations) {
  console.log(`来源${citation.index}: ${citation.snippet}...`);
}
```

## 5. SelfRAG（自反思 RAG）

### 概念说明

SelfRAG 让 LLM 在生成回答的过程中进行自我反思，动态判断是否需要检索、检索结果是否相关、回答是否有依据。这种自反思机制可以显著提升 RAG 系统的回答质量。

### 解决的问题

- 不是所有问题都需要检索（如简单问候、常识问题）
- 检索结果中可能包含不相关的 chunk，需要过滤
- 回答中可能存在幻觉，需要自检
- 传统的 RAG 管道是"一条直线"，缺乏反馈和自纠能力

### TypeScript 类定义

```typescript
/** 自反思标记 */
interface ReflectionTokens {
  /** 是否需要检索 */
  needsRetrieval: boolean;
  /** 检索结果相关性评估 */
  retrievalRelevance?: {
    relevant: boolean;
    score: number;
    reason: string;
  };
  /** 回答是否有依据 */
  isGrounded?: {
    grounded: boolean;
    score: number;
    unsupportedClaims: string[];
  };
}

/** SelfRAG 生成结果 */
interface SelfRAGResult extends GenerateResult {
  /** 反思标记 */
  reflection: ReflectionTokens;
  /** 是否进行了重新生成 */
  regenerated: boolean;
  /** 生成轮次 */
  rounds: number;
}

interface SelfRAGOptions {
  /** 是否启用检索必要性检查 */
  enableRetrievalCheck?: boolean;
  /** 是否启用接地检查 */
  enableGroundingCheck?: boolean;
  /** 最大重新生成次数 */
  maxRetries?: number;
}

class SelfRAGGenerator {
  private llmProvider: LLMProvider;
  private baseGenerator: Generator;
  private options: Required<SelfRAGOptions>;

  constructor(
    llmProvider: LLMProvider,
    baseGenerator: Generator,
    options?: SelfRAGOptions
  ) {
    this.llmProvider = llmProvider;
    this.baseGenerator = baseGenerator;
    this.options = {
      enableRetrievalCheck: options?.enableRetrievalCheck ?? true,
      enableGroundingCheck: options?.enableGroundingCheck ?? true,
      maxRetries: options?.maxRetries ?? 2,
    };
  }

  /**
   * 自反思生成
   * @param query - 用户查询
   * @param chunks - 检索到的文档片段
   * @returns 自反思生成结果
   */
  async generate(
    query: string,
    chunks: SearchResult[]
  ): Promise<SelfRAGResult> {
    const reflection: ReflectionTokens = { needsRetrieval: true };
    let rounds = 0;
    let regenerated = false;

    // 反思点1：需要检索吗？
    if (this.options.enableRetrievalCheck) {
      reflection.needsRetrieval = await this.checkNeedsRetrieval(query);
      if (!reflection.needsRetrieval) {
        // 不需要检索，直接用 LLM 知识回答
        const directAnswer = await this.llmProvider.chat([
          { role: "user", content: query },
        ]);
        return {
          answer: directAnswer.content,
          sources: [],
          metadata: { skippedRetrieval: true },
          reflection,
          regenerated: false,
          rounds: 1,
        };
      }
    }

    // 反思点2：检索结果相关吗？
    let relevantChunks = chunks;
    if (this.options.enableGroundingCheck && chunks.length > 0) {
      const relevance = await this.checkRetrievalRelevance(query, chunks);
      reflection.retrievalRelevance = relevance;

      if (!relevance.relevant) {
        // 检索结果不相关，可能需要调整策略
        relevantChunks = chunks.filter((_, i) => i < Math.min(3, chunks.length));
      }
    }

    // 生成回答
    let result = await this.baseGenerator.generate(query, relevantChunks);

    // 反思点3：回答有依据吗？
    if (this.options.enableGroundingCheck) {
      for (let retry = 0; retry < this.options.maxRetries; retry++) {
        rounds++;
        const grounding = await this.checkGrounding(
          query,
          result.answer,
          relevantChunks
        );
        reflection.isGrounded = grounding;

        if (grounding.grounded) break;

        // 回答不够可靠，重新生成（附加更多约束）
        regenerated = true;
        result = await this.regenerateWithFeedback(
          query,
          relevantChunks,
          grounding.unsupportedClaims
        );
      }
    } else {
      rounds = 1;
    }

    return {
      ...result,
      reflection,
      regenerated,
      rounds,
    };
  }

  private async checkNeedsRetrieval(query: string): Promise<boolean> {
    const response = await this.llmProvider.chat([
      {
        role: "system",
        content: `判断以下问题是否需要检索外部知识库。
简单问候、常识问题不需要检索；专业问题、具体事实查询需要检索。
只回答 "是" 或 "否"。`,
      },
      { role: "user", content: query },
    ]);
    return response.content.trim() === "是";
  }

  private async checkRetrievalRelevance(
    query: string,
    chunks: SearchResult[]
  ): Promise<{ relevant: boolean; score: number; reason: string }> {
    const contextSummary = chunks
      .slice(0, 3)
      .map((c) => c.content.slice(0, 100))
      .join("\n");

    const response = await this.llmProvider.chat([
      {
        role: "system",
        content: `判断以下检索结果是否与用户问题相关。
输出 JSON 格式：{ "relevant": true/false, "score": 0.0-1.0, "reason": "原因" }`,
      },
      {
        role: "user",
        content: `问题：${query}\n\n检索结果摘要：\n${contextSummary}`,
      },
    ]);

    return JSON.parse(response.content);
  }

  private async checkGrounding(
    query: string,
    answer: string,
    chunks: SearchResult[]
  ): Promise<{
    grounded: boolean;
    score: number;
    unsupportedClaims: string[];
  }> {
    const context = chunks.map((c) => c.content).join("\n\n");
    const response = await this.llmProvider.chat([
      {
        role: "system",
        content: `检查以下回答中的每个事实性陈述是否都有参考资料支撑。
输出 JSON：{ "grounded": true/false, "score": 0.0-1.0, "unsupportedClaims": ["无依据的陈述"] }`,
      },
      {
        role: "user",
        content: `参考资料：\n${context}\n\n回答：${answer}`,
      },
    ]);

    return JSON.parse(response.content);
  }

  private async regenerateWithFeedback(
    query: string,
    chunks: SearchResult[],
    unsupportedClaims: string[]
  ): Promise<GenerateResult> {
    const feedback = unsupportedClaims
      .map((claim) => `以下陈述缺乏依据，请修正或移除："${claim}"`)
      .join("\n");

    const messages = [
      {
        role: "system",
        content: `你是一个严谨的助手。请根据参考资料回答问题。
注意以下问题需要修正：\n${feedback}`,
      },
      {
        role: "user",
        content: `参考资料：\n${chunks.map((c) => c.content).join("\n\n")}\n\n问题：${query}`,
      },
    ];

    const response = await this.llmProvider.chat(messages, {
      temperature: 0.2,
    });

    return {
      answer: response.content,
      sources: chunks.map((c) => ({
        id: c.id,
        content: c.content,
        metadata: c.metadata,
      })),
      usage: response.usage,
      metadata: { regenerated: true },
    };
  }
}
```

### 关键参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `enableRetrievalCheck` | `boolean` | `true` | 是否启用检索必要性检查 |
| `enableGroundingCheck` | `boolean` | `true` | 是否启用接地检查 |
| `maxRetries` | `number` | `2` | 接地检查不通过时最大重试次数 |

### 使用示例

```typescript
const selfRAG = new SelfRAGGenerator(llmProvider, baseGenerator, {
  enableRetrievalCheck: true,
  enableGroundingCheck: true,
  maxRetries: 2,
});

// 场景1：需要检索的问题
const result1 = await selfRAG.generate("Kubernetes HPA 自动扩缩容配置方法", chunks);
console.log(result1.reflection);
// {
//   needsRetrieval: true,
//   retrievalRelevance: { relevant: true, score: 0.85 },
//   isGrounded: { grounded: true, score: 0.9, unsupportedClaims: [] }
// }
console.log(`生成轮次: ${result1.rounds}, 是否重新生成: ${result1.regenerated}`);

// 场景2：不需要检索的简单问题
const result2 = await selfRAG.generate("你好", []);
// reflection.needsRetrieval = false，直接用 LLM 回答
```

## 6. ConsistencyChecker（多答案一致性检查）

### 概念说明

对同一个问题生成多个独立回答，然后检查这些回答之间的一致性。如果多个回答一致，说明答案可靠；如果不一致，说明存在争议或不确定性，需要人工确认。

### 解决的问题

- 单次生成可能存在偶然性偏差
- 无法从单次回答中判断答案的可信度
- 一致性是衡量答案可靠性的重要指标

### TypeScript 类定义

```typescript
/** 一致性检查结果 */
interface ConsistencyResult {
  /** 多轮生成的答案列表 */
  answers: string[];
  /** 是否一致 */
  consistent: boolean;
  /** 冲突点描述（如果不一致） */
  conflicts: string[];
  /** 最佳答案（综合多轮结果选出） */
  bestAnswer: string;
  /** 一致性分数 */
  consistencyScore: number;
}

class ConsistencyChecker {
  private llmProvider: LLMProvider;
  private rounds: number;
  private temperature: number;

  constructor(
    llmProvider: LLMProvider,
    options?: {
      /** 生成轮次 */
      rounds?: number;
      /** 生成温度 */
      temperature?: number;
    }
  ) {
    this.llmProvider = llmProvider;
    this.rounds = options?.rounds ?? 3;
    this.temperature = options?.temperature ?? 0.7;
  }

  /**
   * 多轮生成并检查一致性
   * @param query - 用户查询
   * @param chunks - 检索到的文档片段
   * @returns 一致性检查结果
   */
  async check(
    query: string,
    chunks: SearchResult[]
  ): Promise<ConsistencyResult> {
    const context = chunks.map((c) => `[${c.id}] ${c.content}`).join("\n\n");

    // 1. 多轮生成答案
    const answers: string[] = [];
    for (let i = 0; i < this.rounds; i++) {
      const response = await this.llmProvider.chat(
        [
          {
            role: "system",
            content: `请根据以下参考资料准确回答问题。`,
          },
          {
            role: "user",
            content: `参考资料：\n${context}\n\n问题：${query}`,
          },
        ],
        { temperature: this.temperature }
      );
      answers.push(response.content);
    }

    // 2. 检查一致性
    const analysis = await this.analyzeConsistency(query, answers);

    // 3. 选出最佳答案
    const bestAnswer = analysis.consistent
      ? answers[0]
      : await this.selectBestAnswer(query, answers, chunks);

    return {
      answers,
      consistent: analysis.consistent,
      conflicts: analysis.conflicts,
      bestAnswer,
      consistencyScore: analysis.score,
    };
  }

  private async analyzeConsistency(
    query: string,
    answers: string[]
  ): Promise<{ consistent: boolean; conflicts: string[]; score: number }> {
    const answersText = answers
      .map((a, i) => `答案${i + 1}：${a}`)
      .join("\n\n");

    const response = await this.llmProvider.chat([
      {
        role: "system",
        content: `请分析以下多个答案之间的一致性。
输出 JSON：
{
  "consistent": true/false,
  "conflicts": ["冲突描述"],
  "score": 0.0-1.0
}
如果核心事实一致但表述不同，仍视为一致。
如果存在事实性矛盾，视为不一致。`,
      },
      {
        role: "user",
        content: `问题：${query}\n\n${answersText}`,
      },
    ]);

    return JSON.parse(response.content);
  }

  private async selectBestAnswer(
    query: string,
    answers: string[],
    chunks: SearchResult[]
  ): Promise<string> {
    const context = chunks.map((c) => c.content).join("\n\n");
    const answersText = answers
      .map((a, i) => `答案${i + 1}：${a}`)
      .join("\n\n");

    const response = await this.llmProvider.chat([
      {
        role: "system",
        content: `根据参考资料，从多个答案中选出最准确、最完整的一个。
只输出最佳答案的编号（如 "1"），不需要解释。`,
      },
      {
        role: "user",
        content: `参考资料：${context}\n\n问题：${query}\n\n${answersText}`,
      },
    ]);

    const bestIndex = parseInt(response.content.trim(), 10) - 1;
    return answers[Math.max(0, Math.min(bestIndex, answers.length - 1))];
  }
}
```

### 关键参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `rounds` | `number` | `3` | 生成轮次 |
| `temperature` | `number` | `0.7` | 生成温度，控制答案多样性 |

### 使用示例

```typescript
const checker = new ConsistencyChecker(llmProvider, {
  rounds: 3,
  temperature: 0.7,
});

const result = await checker.check("公司的退款政策是什么", searchResults);

if (result.consistent) {
  // 答案一致，可以直接使用
  console.log("✅ 答案一致，可信度高");
  console.log(result.bestAnswer);
} else {
  // 答案有分歧，需要人工确认
  console.log("⚠️ 答案存在分歧");
  console.log(`一致性分数: ${result.consistencyScore}`);
  for (const conflict of result.conflicts) {
    console.log(`冲突: ${conflict}`);
  }
  // 仍然可以使用最佳答案，但建议标注"仅供参考"
  console.log("最佳答案:", result.bestAnswer);
}
```

## 7. LLMJudge（LLM 当裁判）

### 概念说明

使用另一个 LLM（通常与生成回答的 LLM 不同）对回答质量进行多维度评估。评估维度包括准确性、完整性、忠实度、有用性等。

### 解决的问题

- 自动生成回答后缺少质量把控环节
- 人工审核成本高、效率低
- 可以集成到自动化管道中，实现实时质量监控
- 为回答提供可量化的质量指标

### TypeScript 类定义

```typescript
/** 评判结果 */
interface JudgeResult {
  /** 各维度分数（0-10） */
  scores: Record<string, number>;
  /** 综合反馈 */
  feedback: string;
  /** 是否通过质量检查 */
  passed: boolean;
  /** 各维度详细评价 */
  details: Array<{
    dimension: string;
    score: number;
    reasoning: string;
  }>;
}

interface LLMJudgeOptions {
  /** 评估维度 */
  dimensions?: string[];
  /** 各维度的通过阈值（0-10） */
  passThreshold?: number;
  /** 自定义评判提示词 */
  judgePrompt?: string;
}

class LLMJudge {
  private judgeLLM: LLMProvider;
  private options: Required<LLMJudgeOptions>;

  constructor(judgeLLM: LLMProvider, options?: LLMJudgeOptions) {
    this.judgeLLM = judgeLLM;
    this.options = {
      dimensions: options?.dimensions ?? [
        "准确性",
        "完整性",
        "忠实度",
        "有用性",
      ],
      passThreshold: options?.passThreshold ?? 6,
      judgePrompt: options?.judgePrompt ?? this.getDefaultPrompt(),
    };
  }

  /**
   * 评估回答质量
   * @param query - 用户原始查询
   * @param answer - LLM 生成的回答
   * @param context - 检索到的参考资料
   * @returns 评判结果
   */
  async judge(
    query: string,
    answer: string,
    context: string
  ): Promise<JudgeResult> {
    const dimensionsList = this.options.dimensions.join("、");

    const response = await this.judgeLLM.chat([
      {
        role: "system",
        content: this.options.judgePrompt,
      },
      {
        role: "user",
        content: `请从以下维度评估回答质量：${dimensionsList}

用户问题：${query}

参考资料：
${context}

待评估的回答：
${answer}

请以 JSON 格式输出评估结果：
{
  "details": [
    {
      "dimension": "维度名",
      "score": 0-10,
      "reasoning": "评价理由"
    }
  ],
  "feedback": "综合反馈"
}`,
      },
    ]);

    const parsed = JSON.parse(response.content) as {
      details: Array<{
        dimension: string;
        score: number;
        reasoning: string;
      }>;
      feedback: string;
    };

    // 构建分数映射
    const scores: Record<string, number> = {};
    for (const detail of parsed.details) {
      scores[detail.dimension] = detail.score;
    }

    // 判断是否通过：所有维度都达到阈值
    const passed = parsed.details.every(
      (d) => d.score >= this.options.passThreshold
    );

    return {
      scores,
      feedback: parsed.feedback,
      passed,
      details: parsed.details,
    };
  }

  private getDefaultPrompt(): string {
    return `你是一个严格的回答质量评估专家。请从以下维度评估回答：

1. 准确性：回答中的事实是否正确
2. 完整性：是否覆盖了问题的所有方面
3. 忠实度：回答是否忠于参考资料，有没有编造信息
4. 有用性：回答对用户是否真正有帮助

评分范围：0-10 分。
请给出客观、严格的评价。`;
  }
}
```

### 关键参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `dimensions` | `string[]` | `["准确性", "完整性", "忠实度", "有用性"]` | 评估维度 |
| `passThreshold` | `number` | `6` | 各维度通过阈值（0-10） |
| `judgePrompt` | `string` | 内置默认模板 | 自定义评判提示词 |

### 使用示例

```typescript
// 使用不同于生成模型的 LLM 作为裁判
const judge = new LLMJudge(judgeLLMProvider, {
  dimensions: ["准确性", "完整性", "忠实度", "有用性", "简洁性"],
  passThreshold: 7,
});

// 先获取生成结果
const generateResult = await generator.generate(query, searchResults);

// 再评估质量
const judgeResult = await judge.judge(
  query,
  generateResult.answer,
  searchResults.map((r) => r.content).join("\n\n")
);

console.log(`是否通过: ${judgeResult.passed ? "✅ 通过" : "❌ 未通过"}`);
console.log("各维度分数:");
for (const detail of judgeResult.details) {
  const bar = "█".repeat(detail.score) + "░".repeat(10 - detail.score);
  console.log(`  ${detail.dimension}: [${bar}] ${detail.score}/10`);
  console.log(`    ${detail.reasoning}`);
}
console.log(`综合反馈: ${judgeResult.feedback}`);

// 未通过时的处理策略
if (!judgeResult.passed) {
  console.log("回答质量不达标，建议人工审核或重新生成");
  // 可以触发重新生成、降级回答、或通知管理员
}
```

## 模块组合使用

生成模块的各个组件可以灵活组合，构建不同复杂度的生成管道：

```typescript
/**
 * 完整的高质量生成管道示例
 */
async function buildGenerationPipeline(
  query: string,
  searchResults: SearchResult[]
): Promise<{
  result: CitationGenerateResult;
  judgeResult: JudgeResult;
}> {
  // 1. 带引用的回答生成
  const citationGen = new CitationGenerator(llmProvider);
  const result = await citationGen.generate(query, searchResults, {
    model: "gpt-4o",
    temperature: 0.2,
  });

  // 2. LLM 裁判评估质量
  const judge = new LLMJudge(judgeLLMProvider, { passThreshold: 7 });
  const judgeResult = await judge.judge(
    query,
    result.citedAnswer,
    searchResults.map((r) => r.content).join("\n\n")
  );

  // 3. 如果不通过，尝试重新生成
  if (!judgeResult.passed) {
    const retryResult = await citationGen.generate(query, searchResults, {
      model: "gpt-4o",
      temperature: 0.1, // 更低温度，更保守
    });

    return { result: retryResult, judgeResult };
  }

  return { result, judgeResult };
}
```
