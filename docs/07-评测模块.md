# 评测模块

> 评测是 RAG 系统持续优化的基石。本模块从三个维度对系统进行全面评估：检索质量、生成质量、端到端效果。

---

## 一、检索评测 (Retrieval Evaluation)

检索评测回答一个核心问题：**检索器找到的文档，到底好不好？**

### 公共接口定义

```typescript
/** 检索评测器接口 */
interface RetrievalEvaluator {
  /** 评估器名称 */
  readonly name: string;
  /** 执行评测 */
  evaluate(results: SearchResult[], groundTruth: string[]): MetricResult;
}

/** 检索结果 */
interface SearchResult {
  id: string;
  content: string;
  score: number;
  metadata?: Record<string, unknown>;
}

/** 评测结果 */
interface MetricResult {
  metric: string;
  score: number;
  details?: Record<string, unknown>;
}
```

---

### 1.1 Recall@K（召回率）

#### 概念说明

Recall@K 衡量的是：在所有相关文档中，检索系统成功找到了多少。它回答的是 **"有没有漏掉"** 这个问题。

#### 计算公式

```
Recall@K = |检索到的相关文档 ∩ 所有相关文档| / |所有相关文档|
```

#### 核心特性

- K 越大，Recall 越高（检索范围越广，越不容易遗漏）
- 当 K = 全部文档数时，Recall = 1.0
- 侧重"找全"，对"找准"不敏感

#### 适用场景

- 法律检索：不能遗漏任何相关判例
- 医疗诊断：需要找到所有相关病例
- 合规审查：必须覆盖所有相关条款

#### 类定义

```typescript
interface RecallEvaluatorOptions {
  /** 取前 K 个结果进行评测，默认 10 */
  k?: number;
}

class RecallEvaluator implements RetrievalEvaluator {
  readonly name = 'Recall@K';
  private readonly k: number;

  constructor(options: RecallEvaluatorOptions = {}) {
    this.k = options.k ?? 10;
  }

  evaluate(results: SearchResult[], groundTruth: string[]): MetricResult {
    const topK = results.slice(0, this.k);
    const groundTruthSet = new Set(groundTruth);
    const retrievedRelevant = topK.filter((r) => groundTruthSet.has(r.id));

    const score =
      groundTruth.length === 0
        ? 0
        : retrievedRelevant.length / groundTruth.length;

    return {
      metric: this.name,
      score,
      details: {
        k: this.k,
        retrievedRelevantCount: retrievedRelevant.length,
        totalRelevantCount: groundTruth.length,
      },
    };
  }
}
```

#### 使用示例

```typescript
const evaluator = new RecallEvaluator({ k: 5 });

const results: SearchResult[] = [
  { id: 'doc1', content: '...', score: 0.95 },
  { id: 'doc2', content: '...', score: 0.90 },
  { id: 'doc3', content: '...', score: 0.85 },
  { id: 'doc4', content: '...', score: 0.80 },
  { id: 'doc5', content: '...', score: 0.75 },
];

// 人工标注的相关文档 ID
const groundTruth = ['doc1', 'doc3', 'doc7', 'doc9'];

const result = evaluator.evaluate(results, groundTruth);
// result.score = 2/4 = 0.5（找到了 doc1 和 doc3，漏掉了 doc7 和 doc9）
```

### 1.2 Precision@K（精确率）

#### 概念说明

Precision@K 衡量的是：检索到的前 K 个结果中，有多少是真正相关的。它回答的是 **"结果干不干净"** 这个问题。

#### 计算公式

```
Precision@K = |Top-K 中相关的文档| / K
```

#### 核心特性

- K 越大，Precision 通常越低（靠后的结果相关性递减）
- 侧重"找准"，对"找全"不敏感
- 分母固定为 K，不受 ground truth 总量影响

#### 适用场景

- 搜索引擎首页：用户只看前几条，要求每条都相关
- 推荐系统：推荐列表中的每个推荐都要"靠谱"
- 用户面向的搜索结果展示

#### 类定义

```typescript
interface PrecisionEvaluatorOptions {
  /** 取前 K 个结果进行评测，默认 10 */
  k?: number;
}

class PrecisionEvaluator implements RetrievalEvaluator {
  readonly name = 'Precision@K';
  private readonly k: number;

  constructor(options: PrecisionEvaluatorOptions = {}) {
    this.k = options.k ?? 10;
  }

  evaluate(results: SearchResult[], groundTruth: string[]): MetricResult {
    const topK = results.slice(0, this.k);
    const groundTruthSet = new Set(groundTruth);
    const relevantCount = topK.filter((r) => groundTruthSet.has(r.id)).length;

    const score = topK.length === 0 ? 0 : relevantCount / this.k;

    return {
      metric: this.name,
      score,
      details: {
        k: this.k,
        relevantCount,
        totalRetrieved: topK.length,
      },
    };
  }
}
```

#### 使用示例

```typescript
const evaluator = new PrecisionEvaluator({ k: 5 });

const results: SearchResult[] = [
  { id: 'doc1', content: '...', score: 0.95 },
  { id: 'doc2', content: '...', score: 0.90 },
  { id: 'doc3', content: '...', score: 0.85 },
  { id: 'doc4', content: '...', score: 0.80 },
  { id: 'doc5', content: '...', score: 0.75 },
];

const groundTruth = ['doc1', 'doc3'];

const result = evaluator.evaluate(results, groundTruth);
// result.score = 2/5 = 0.4（5 个结果中有 2 个相关）
```

### 1.3 MRR（Mean Reciprocal Rank，平均倒数排名）

#### 概念说明

MRR 衡量的是：第一个相关结果排在第几位。它回答的是 **"用户要翻到第几个才能看到正确答案"** 这个问题。

#### 计算公式

```
RR = 1 / 第一个相关结果的排名位置
MRR = (1/Q) * Σ RR_q  （Q 个查询的 RR 平均值）
```

#### 核心特性

- 只关心第一个相关结果，后续相关结果不影响分数
- 排名越靠前，分数越接近 1
- 如果第一个结果就相关，RR = 1.0

#### 适用场景

- 问答系统：用户只需要一个正确答案
- FAQ 系统：找到最匹配的那条 FAQ
- 精确查找：如"XX 公司的 CEO 是谁"

#### 类定义

```typescript
class MRREvaluator implements RetrievalEvaluator {
  readonly name = 'MRR';

  evaluate(results: SearchResult[], groundTruth: string[]): MetricResult {
    const groundTruthSet = new Set(groundTruth);
    let firstRelevantRank = -1;

    for (let i = 0; i < results.length; i++) {
      if (groundTruthSet.has(results[i].id)) {
        firstRelevantRank = i + 1; // 排名从 1 开始
        break;
      }
    }

    const score = firstRelevantRank === -1 ? 0 : 1 / firstRelevantRank;

    return {
      metric: this.name,
      score,
      details: {
        firstRelevantRank,
      },
    };
  }
}
```

#### 使用示例

```typescript
const evaluator = new MRREvaluator();

// 场景1：第一个结果就相关
const results1: SearchResult[] = [
  { id: 'doc1', content: '...', score: 0.95 },
  { id: 'doc2', content: '...', score: 0.90 },
];
const gt1 = ['doc1'];
evaluator.evaluate(results1, gt1);
// score = 1/1 = 1.0

// 场景2：第三个结果才相关
const results2: SearchResult[] = [
  { id: 'doc5', content: '...', score: 0.95 },
  { id: 'doc6', content: '...', score: 0.90 },
  { id: 'doc1', content: '...', score: 0.85 },
];
evaluator.evaluate(results2, gt1);
// score = 1/3 ≈ 0.333

// 场景3：没有相关结果
const results3: SearchResult[] = [
  { id: 'doc5', content: '...', score: 0.95 },
];
evaluator.evaluate(results3, gt1);
// score = 0
```

### 1.4 NDCG（Normalized Discounted Cumulative Gain）

#### 概念说明

NDCG 是最全面的检索指标，**同时考虑相关性等级和排名位置**。它回答的是："排序结果是不是接近理想的完美排序？"

#### 计算步骤

1. **DCG（Discounted Cumulative Gain）**：对每个位置的相关性打分，位置越后折扣越大
   ```
   DCG@K = Σ(i=1 to K) rel_i / log₂(i+1)
   ```

2. **IDCG（Ideal DCG）**：按理想排序（相关性从高到低）计算的 DCG
   ```
   IDCG@K = 将相关性分数降序排列后计算的 DCG
   ```

3. **NDCG**：归一化
   ```
   NDCG@K = DCG@K / IDCG@K
   ```
   范围 [0, 1]，越接近 1 说明排序越接近理想状态

#### 核心特性

- 需要人工标注每个结果的**相关性等级**（通常 0-3 分）
- 同时考虑了"找得准"和"排得好"
- 业界公认的最全面的排序质量指标

#### 适用场景

- 综合评估排序质量
- 搜索引擎排名算法调优
- 推荐系统排序效果评估

#### 类定义

```typescript
interface NDCGEvaluatorOptions {
  /** 取前 K 个结果进行评测，默认 10 */
  k?: number;
}

class NDCGEvaluator implements RetrievalEvaluator {
  readonly name = 'NDCG@K';
  private readonly k: number;

  constructor(options: NDCGEvaluatorOptions = {}) {
    this.k = options.k ?? 10;
  }

  /**
   * NDCG 评测需要额外的相关性分数
   * @param results 检索结果列表
   * @param groundTruth 相关文档 ID 列表（用于兼容接口）
   * @param relevanceScores 每个文档 ID 对应的相关性等级（0-3）
   */
  evaluate(
    results: SearchResult[],
    groundTruth: string[],
    relevanceScores?: Map<string, number>,
  ): MetricResult {
    const topK = results.slice(0, this.k);
    const scores = relevanceScores ?? this.buildDefaultScores(groundTruth);

    // 计算 DCG：按当前排序
    const dcg = this.computeDCG(topK, scores);

    // 计算 IDCG：按理想排序（相关性降序）
    const idealScores = topK
      .map((r) => scores.get(r.id) ?? 0)
      .sort((a, b) => b - a);
    const idcg = this.computeDCGFromScores(idealScores);

    const ndcg = idcg === 0 ? 0 : dcg / idcg;

    return {
      metric: this.name,
      score: ndcg,
      details: {
        k: this.k,
        dcg,
        idcg,
      },
    };
  }

  private computeDCG(
    results: SearchResult[],
    scores: Map<string, number>,
  ): number {
    let dcg = 0;
    for (let i = 0; i < results.length; i++) {
      const rel = scores.get(results[i].id) ?? 0;
      dcg += rel / Math.log2(i + 2); // i+2 因为位置从 1 开始，log₂(1+1)=1
    }
    return dcg;
  }

  private computeDCGFromScores(scores: number[]): number {
    let dcg = 0;
    for (let i = 0; i < scores.length; i++) {
      dcg += scores[i] / Math.log2(i + 2);
    }
    return dcg;
  }

  /**
   * 如果没有提供相关性分数，默认 ground truth 中的文档相关性为 1
   */
  private buildDefaultScores(groundTruth: string[]): Map<string, number> {
    const scores = new Map<string, number>();
    for (const id of groundTruth) {
      scores.set(id, 1);
    }
    return scores;
  }
}
```

#### 使用示例

```typescript
const evaluator = new NDCGEvaluator({ k: 5 });

const results: SearchResult[] = [
  { id: 'doc1', content: '...', score: 0.95 },
  { id: 'doc2', content: '...', score: 0.90 },
  { id: 'doc3', content: '...', score: 0.85 },
  { id: 'doc4', content: '...', score: 0.80 },
  { id: 'doc5', content: '...', score: 0.75 },
];

// 人工标注的相关性等级：3=非常相关，2=相关，1=部分相关，0=不相关
const relevanceScores = new Map<string, number>([
  ['doc1', 3],
  ['doc2', 0],
  ['doc3', 2],
  ['doc4', 1],
  ['doc5', 0],
]);

const result = evaluator.evaluate(results, [], relevanceScores);
// DCG  = 3/log₂(2) + 0/log₂(3) + 2/log₂(4) + 1/log₂(5) + 0/log₂(6)
//      = 3/1 + 0/1.58 + 2/2 + 1/2.32 + 0/2.58
//      = 3 + 0 + 1 + 0.43 + 0 = 4.43
// IDCG（理想排序：3,2,1,0,0）
//      = 3/1 + 2/1.58 + 1/2 + 0 + 0 = 3 + 1.27 + 0.5 = 4.77
// NDCG = 4.43 / 4.77 ≈ 0.929
```

### 1.5 批量评测工具 (RetrievalBenchmark)

#### 概念说明

单个 query 的评测结果具有偶然性。批量评测工具通过**在多个 query 上取平均**，得到更具统计意义的评测结果。

#### 类定义

```typescript
/** 评测数据集条目 */
interface BenchmarkDataset {
  /** 查询文本 */
  query: string;
  /** 相关文档 ID 列表 */
  relevantIds: string[];
  /** 可选：每个文档的相关性等级（用于 NDCG 等指标） */
  relevanceScores?: Map<string, number>;
}

/** 评测报告 */
interface BenchmarkReport {
  /** 各指标的平均得分 */
  metrics: Record<string, number>;
  /** 每个 query 的单独得分 */
  perQuery: Array<Record<string, number>>;
  /** 评测数据条数 */
  totalQueries: number;
  /** 使用的评估器列表 */
  evaluators: string[];
}

class RetrievalBenchmark {
  private readonly evaluators: RetrievalEvaluator[];
  private readonly retriever: Retriever;

  constructor(evaluators: RetrievalEvaluator[], retriever: Retriever) {
    this.evaluators = evaluators;
    this.retriever = retriever;
  }

  /**
   * 对整个数据集执行批量评测
   * @param dataset 评测数据集
   * @returns 评测报告
   */
  async benchmark(dataset: BenchmarkDataset[]): Promise<BenchmarkReport> {
    const perQuery: Array<Record<string, number>> = [];

    for (const item of dataset) {
      // 执行检索
      const results = await this.retriever.retrieve(item.query);

      // 对每个评估器执行评测
      const queryScores: Record<string, number> = {};
      for (const evaluator of this.evaluators) {
        const result =
          evaluator instanceof NDCGEvaluator
            ? evaluator.evaluate(results, item.relevantIds, item.relevanceScores)
            : evaluator.evaluate(results, item.relevantIds);
        queryScores[evaluator.name] = result.score;
      }
      perQuery.push(queryScores);
    }

    // 计算各指标平均值
    const metrics: Record<string, number> = {};
    for (const evaluator of this.evaluators) {
      const scores = perQuery.map((q) => q[evaluator.name] ?? 0);
      metrics[evaluator.name] =
        scores.reduce((sum, s) => sum + s, 0) / scores.length;
    }

    return {
      metrics,
      perQuery,
      totalQueries: dataset.length,
      evaluators: this.evaluators.map((e) => e.name),
    };
  }
}
```

#### 使用示例

```typescript
// 1. 创建评估器
const evaluators: RetrievalEvaluator[] = [
  new RecallEvaluator({ k: 5 }),
  new PrecisionEvaluator({ k: 5 }),
  new MRREvaluator(),
  new NDCGEvaluator({ k: 5 }),
];

// 2. 准备评测数据集
const dataset: BenchmarkDataset[] = [
  {
    query: '什么是机器学习？',
    relevantIds: ['doc1', 'doc5', 'doc12'],
    relevanceScores: new Map([
      ['doc1', 3],
      ['doc5', 2],
      ['doc12', 1],
    ]),
  },
  {
    query: '深度学习的应用场景',
    relevantIds: ['doc3', 'doc7'],
    relevanceScores: new Map([
      ['doc3', 3],
      ['doc7', 2],
    ]),
  },
  // ... 更多数据
];

// 3. 执行批量评测
const benchmark = new RetrievalBenchmark(evaluators, myRetriever);
const report = await benchmark.benchmark(dataset);

console.log('各指标平均分:', report.metrics);
// { 'Recall@K': 0.75, 'Precision@K': 0.60, 'MRR': 0.83, 'NDCG@K': 0.71 }

console.log('每个 query 的得分:', report.perQuery);
```

### 2.1 BLEU

#### 概念说明

BLEU（Bilingual Evaluation Understudy）通过比较生成答案和参考答案的 **n-gram 重合度**来衡量生成质量。最初用于机器翻译评测，后广泛用于各种文本生成任务。

#### 计算步骤

1. 计算 1-gram 到 N-gram（通常 N=4）的精确率
2. 取几何平均
3. 乘以长度惩罚因子（Brevity Penalty），防止生成过短的答案

#### 核心特性

- 优点：计算快速，不需要外部模型
- 缺点：只看字面重合，不懂语义。"猫在睡觉"和"一只猫正在睡觉"得分会很低
- 适合：摘要、翻译等对措辞有要求的任务

#### 类定义

```typescript
interface BLEUEvaluatorOptions {
  /** 最大 n-gram 阶数，默认 4 */
  maxN?: number;
}

class BLEUEvaluator implements GenerationEvaluator {
  readonly name = 'BLEU';
  private readonly maxN: number;

  constructor(options: BLEUEvaluatorOptions = {}) {
    this.maxN = options.maxN ?? 4;
  }

  evaluate(answer: string, reference: string): MetricResult {
    const answerTokens = this.tokenize(answer);
    const referenceTokens = this.tokenize(reference);

    // 计算各阶 n-gram 精确率
    const precisions: number[] = [];
    for (let n = 1; n <= this.maxN; n++) {
      const answerNgrams = this.getNgrams(answerTokens, n);
      const referenceNgrams = this.getNgrams(referenceTokens, n);

      let matches = 0;
      let total = 0;
      const refCounts = new Map<string, number>();

      for (const [ngram, count] of referenceNgrams) {
        refCounts.set(ngram, count);
      }

      for (const [ngram, count] of answerNgrams) {
        const refCount = refCounts.get(ngram) ?? 0;
        matches += Math.min(count, refCount);
        total += count;
      }

      precisions.push(total === 0 ? 0 : matches / total);
    }

    // 几何平均（用对数避免下溢）
    const logAvg =
      precisions.reduce((sum, p) => sum + (p > 0 ? Math.log(p) : -Infinity), 0) /
      this.maxN;
    const bleu = Math.exp(logAvg);

    // 长度惩罚因子（Brevity Penalty）
    const bp =
      answerTokens.length >= referenceTokens.length
        ? 1
        : Math.exp(1 - referenceTokens.length / answerTokens.length);

    const score = bp * bleu;

    return {
      metric: this.name,
      score,
      details: {
        precisions,
        brevityPenalty: bp,
        answerLength: answerTokens.length,
        referenceLength: referenceTokens.length,
      },
    };
  }

  /** 将文本拆分为 token（简单按空格和标点分词） */
  private tokenize(text: string): string[] {
    return text
      .toLowerCase()
      .split(/[\s,.!?;:，。！？；：]+/)
      .filter((t) => t.length > 0);
  }

  /** 提取 n-gram 并统计频次 */
  private getNgrams(tokens: string[], n: number): Map<string, number> {
    const ngrams = new Map<string, number>();
    for (let i = 0; i <= tokens.length - n; i++) {
      const ngram = tokens.slice(i, i + n).join(' ');
      ngrams.set(ngram, (ngrams.get(ngram) ?? 0) + 1);
    }
    return ngrams;
  }
}
```

#### 使用示例

```typescript
const evaluator = new BLEUEvaluator({ maxN: 4 });

const answer = '机器学习是人工智能的一个分支';
const reference = '机器学习是人工智能领域的一个重要分支';

const result = evaluator.evaluate(answer, reference);
console.log(result.score); // 0.x，取决于 n-gram 重合度
console.log(result.details?.precisions); // [1-gram精确率, 2-gram精确率, ...]
```

### 2.2 ROUGE

#### 概念说明

ROUGE（Recall-Oriented Understudy for Gisting Evaluation）从**召回率视角**衡量参考答案被生成答案覆盖了多少。与 BLEU 互补——BLEU 关注精确率，ROUGE 关注召回率。

#### 变体说明

| 变体 | 说明 |
|------|------|
| ROUGE-1 | 基于单词（unigram）的重合度 |
| ROUGE-2 | 基于双词（bigram）的重合度 |
| ROUGE-L | 基于最长公共子序列（LCS），不要求连续但要求顺序一致 |

#### 类定义

```typescript
interface ROUGEEvaluatorOptions {
  /** 变体：'1'（单词）、'2'（双词）、'L'（最长公共子序列） */
  variant?: '1' | '2' | 'L';
}

class ROUGEEvaluator implements GenerationEvaluator {
  readonly name: string;
  private readonly variant: '1' | '2' | 'L';

  constructor(options: ROUGEEvaluatorOptions = {}) {
    this.variant = options.variant ?? 'L';
    this.name = `ROUGE-${this.variant}`;
  }

  evaluate(answer: string, reference: string): MetricResult {
    const answerTokens = this.tokenize(answer);
    const referenceTokens = this.tokenize(reference);

    let precision: number;
    let recall: number;
    let f1: number;

    if (this.variant === 'L') {
      // ROUGE-L：基于最长公共子序列
      const lcsLength = this.computeLCS(answerTokens, referenceTokens);
      precision = answerTokens.length === 0 ? 0 : lcsLength / answerTokens.length;
      recall = referenceTokens.length === 0 ? 0 : lcsLength / referenceTokens.length;
      f1 =
        precision + recall === 0
          ? 0
          : (2 * precision * recall) / (precision + recall);
    } else {
      // ROUGE-1 或 ROUGE-2：基于 n-gram
      const n = this.variant === '1' ? 1 : 2;
      const answerNgrams = this.getNgrams(answerTokens, n);
      const referenceNgrams = this.getNgrams(referenceTokens, n);

      let matches = 0;
      for (const [ngram, count] of answerNgrams) {
        const refCount = referenceNgrams.get(ngram) ?? 0;
        matches += Math.min(count, refCount);
      }

      const answerTotal = answerTokens.length - n + 1;
      const referenceTotal = referenceTokens.length - n + 1;

      precision = answerTotal <= 0 ? 0 : matches / answerTotal;
      recall = referenceTotal <= 0 ? 0 : matches / referenceTotal;
      f1 =
        precision + recall === 0
          ? 0
          : (2 * precision * recall) / (precision + recall);
    }

    return {
      metric: this.name,
      score: f1,
      details: { precision, recall, f1 },
    };
  }

  private tokenize(text: string): string[] {
    return text
      .toLowerCase()
      .split(/[\s,.!?;:，。！？；：]+/)
      .filter((t) => t.length > 0);
  }

  private getNgrams(tokens: string[], n: number): Map<string, number> {
    const ngrams = new Map<string, number>();
    for (let i = 0; i <= tokens.length - n; i++) {
      const ngram = tokens.slice(i, i + n).join(' ');
      ngrams.set(ngram, (ngrams.get(ngram) ?? 0) + 1);
    }
    return ngrams;
  }

  /**
   * 使用动态规划计算最长公共子序列（LCS）长度
   * 时间复杂度 O(m*n)，空间复杂度 O(min(m,n))
   */
  private computeLCS(a: string[], b: string[]): number {
    const m = a.length;
    const n = b.length;

    // 使用滚动数组优化空间
    let prev = new Array(n + 1).fill(0);
    let curr = new Array(n + 1).fill(0);

    for (let i = 1; i <= m; i++) {
      for (let j = 1; j <= n; j++) {
        if (a[i - 1] === b[j - 1]) {
          curr[j] = prev[j - 1] + 1;
        } else {
          curr[j] = Math.max(prev[j], curr[j - 1]);
        }
      }
      [prev, curr] = [curr, prev];
      curr.fill(0);
    }

    return prev[n];
  }
}
```

### 2.3 BERTScore

#### 概念说明

BERTScore 不依赖字面重合，而是用 **BERT Embedding 的语义相似度**来评估生成质量。即使生成文本和参考文本措辞完全不同，只要语义相似就能获得高分。

#### 计算步骤

1. 将候选文本和参考文本分别通过 BERT 编码，得到每个 token 的向量表示
2. 计算候选 token 和参考 token 之间的余弦相似度矩阵
3. 对矩阵做最优匹配，得到 Precision、Recall、F1

#### 核心特性

- 优势：语义相似但字面不同也能得高分（如"高兴"和"开心"）
- 劣势：依赖外部 Embedding 模型，计算成本较高
- 比 BLEU/ROUGE 更接近人类判断

#### 类定义

```typescript
/** Embedding 提供者接口（外部依赖） */
interface EmbeddingProvider {
  /** 将文本编码为向量序列（每个 token 一个向量） */
  encode(text: string): Promise<number[][]>;
}

class BERTScoreEvaluator implements GenerationEvaluator {
  readonly name = 'BERTScore';
  private readonly embeddingProvider: EmbeddingProvider;

  constructor(embeddingProvider: EmbeddingProvider) {
    this.embeddingProvider = embeddingProvider;
  }

  async evaluate(answer: string, reference: string): Promise<MetricResult> {
    // 分别编码两个文本
    const answerEmbeddings = await this.embeddingProvider.encode(answer);
    const referenceEmbeddings = await this.embeddingProvider.encode(reference);

    // 计算余弦相似度矩阵
    const simMatrix = this.computeSimilarityMatrix(
      answerEmbeddings,
      referenceEmbeddings,
    );

    // Precision：对每个候选 token，找最佳匹配的参考 token
    const precision = this.computeMaxAvg(simMatrix, 'row');

    // Recall：对每个参考 token，找最佳匹配的候选 token
    const recall = this.computeMaxAvg(simMatrix, 'col');

    // F1
    const f1 =
      precision + recall === 0
        ? 0
        : (2 * precision * recall) / (precision + recall);

    return {
      metric: this.name,
      score: f1,
      details: { precision, recall, f1 },
    };
  }

  /** 计算余弦相似度矩阵 */
  private computeSimilarityMatrix(
    a: number[][],
    b: number[][],
  ): number[][] {
    const matrix: number[][] = [];
    for (const vecA of a) {
      const row: number[] = [];
      for (const vecB of b) {
        row.push(this.cosineSimilarity(vecA, vecB));
      }
      matrix.push(row);
    }
    return matrix;
  }

  /** 余弦相似度 */
  private cosineSimilarity(a: number[], b: number[]): number {
    let dot = 0;
    let normA = 0;
    let normB = 0;
    for (let i = 0; i < a.length; i++) {
      dot += a[i] * b[i];
      normA += a[i] * a[i];
      normB += b[i] * b[i];
    }
    const denom = Math.sqrt(normA) * Math.sqrt(normB);
    return denom === 0 ? 0 : dot / denom;
  }

  /** 计算行或列的最大值平均 */
  private computeMaxAvg(
    matrix: number[][],
    direction: 'row' | 'col',
  ): number {
    if (matrix.length === 0 || matrix[0].length === 0) return 0;

    if (direction === 'row') {
      // 每行取最大值，再求平均
      const maxValues = matrix.map((row) => Math.max(...row));
      return maxValues.reduce((a, b) => a + b, 0) / maxValues.length;
    } else {
      // 每列取最大值，再求平均
      const cols = matrix[0].length;
      let sum = 0;
      for (let j = 0; j < cols; j++) {
        let max = -Infinity;
        for (const row of matrix) {
          max = Math.max(max, row[j]);
        }
        sum += max;
      }
      return sum / cols;
    }
  }
}
```

### 2.4 Faithfulness（忠实度）

#### 概念说明

Faithfulness 衡量的是：回答是否忠实于检索到的参考资料，**有没有编造不存在的信息**（即"幻觉"）。这是 RAG 系统最关键的评测维度之一。

#### 工作原理

1. 将生成的回答拆分为独立的断言（claim）
2. 对每个断言，用 LLM 判断是否有检索资料支撑
3. 统计有支撑的断言比例

#### 类定义

```typescript
/** LLM 提供者接口（外部依赖） */
interface LLMProvider {
  chat(messages: ChatMessage[], options?: LLMOptions): Promise<string>;
}

interface ChatMessage {
  role: 'system' | 'user' | 'assistant';
  content: string;
}

interface LLMOptions {
  temperature?: number;
  maxTokens?: number;
  responseFormat?: 'text' | 'json';
}

interface FaithfulnessResult extends MetricResult {
  /** 未被支撑的断言列表（幻觉） */
  unsupportedClaims: string[];
}

class FaithfulnessEvaluator implements GenerationEvaluator {
  readonly name = 'Faithfulness';
  private readonly llmProvider: LLMProvider;

  constructor(llmProvider: LLMProvider) {
    this.llmProvider = llmProvider;
  }

  async evaluate(
    answer: string,
    _reference: string,
    context?: GenerationEvalContext,
  ): Promise<MetricResult> {
    const contextTexts = context?.context;
    if (!contextTexts || contextTexts.length === 0) {
      return {
        metric: this.name,
        score: 0,
        details: { error: '未提供检索资料，无法评估忠实度' },
      };
    }

    const contextStr = contextTexts.join('\n---\n');

    // 用 LLM 逐句检查断言是否有资料支撑
    const prompt = `你是一个严格的评审员。请检查以下回答中的每个断言是否有提供的资料支撑。

## 检索资料
${contextStr}

## 回答
${answer}

## 要求
请以 JSON 格式返回结果：
{
  "claims": [
    {
      "text": "断言内容",
      "supported": true/false,
      "reason": "判断理由"
    }
  ]
}`;

    const response = await this.llmProvider.chat(
      [
        { role: 'system', content: '你是一个严格的事实核查员，只基于提供的资料进行判断。' },
        { role: 'user', content: prompt },
      ],
      { temperature: 0, responseFormat: 'json' },
    );

    const parsed = JSON.parse(response) as {
      claims: Array<{ text: string; supported: boolean; reason: string }>;
    };

    const unsupportedClaims = parsed.claims
      .filter((c) => !c.supported)
      .map((c) => c.text);

    const supportedCount = parsed.claims.filter((c) => c.supported).length;
    const score =
      parsed.claims.length === 0
        ? 1
        : supportedCount / parsed.claims.length;

    return {
      metric: this.name,
      score,
      details: {
        totalClaims: parsed.claims.length,
        supportedClaims: supportedCount,
        unsupportedClaims,
      },
    } as FaithfulnessResult;
  }
}
```

### 2.5 AnswerRelevance（答案相关性）

#### 概念说明

AnswerRelevance 衡量的是：回答和用户问题有多相关，**有没有答到点上**。即使回答本身质量很高，但如果答非所问，分数也会很低。

### 2.6 批量评测工具 (GenerationBenchmark)

#### 概念说明

类似 RetrievalBenchmark，针对生成评测的批量评测工具。支持同时运行多个评估器，并对多个 QA 对取平均。

#### 类定义

```typescript
/** 生成评测数据集条目 */
interface GenerationDataset {
  /** 用户问题 */
  query: string;
  /** 系统生成的回答 */
  answer: string;
  /** 参考答案 */
  reference: string;
  /** 检索到的参考资料 */
  context?: string[];
}

/** 生成评测报告 */
interface GenerationReport {
  /** 各指标的平均得分 */
  metrics: Record<string, number>;
  /** 每个 QA 对的单独得分 */
  perItem: Array<Record<string, number>>;
  /** 评测数据条数 */
  totalItems: number;
  /** 使用的评估器列表 */
  evaluators: string[];
}

class GenerationBenchmark {
  private readonly evaluators: GenerationEvaluator[];

  constructor(evaluators: GenerationEvaluator[]) {
    this.evaluators = evaluators;
  }

  /**
   * 对整个数据集执行批量评测
   * @param dataset 生成评测数据集
   * @returns 评测报告
   */
  async benchmark(dataset: GenerationDataset[]): Promise<GenerationReport> {
    const perItem: Array<Record<string, number>> = [];

    for (const item of dataset) {
      const itemScores: Record<string, number> = {};
      const context: GenerationEvalContext = {
        query: item.query,
        context: item.context,
      };

      // 并行运行所有评估器
      const results = await Promise.all(
        this.evaluators.map((evaluator) =>
          evaluator.evaluate(item.answer, item.reference, context),
        ),
      );

      for (let i = 0; i < this.evaluators.length; i++) {
        itemScores[this.evaluators[i].name] = results[i].score;
      }

      perItem.push(itemScores);
    }

    // 计算各指标平均值
    const metrics: Record<string, number> = {};
    for (const evaluator of this.evaluators) {
      const scores = perItem.map((item) => item[evaluator.name] ?? 0);
      metrics[evaluator.name] =
        scores.reduce((sum, s) => sum + s, 0) / scores.length;
    }

    return {
      metrics,
      perItem,
      totalItems: dataset.length,
      evaluators: this.evaluators.map((e) => e.name),
    };
  }
}
```

## 三、端到端评测 (End-to-End Evaluation)

端到端评测回答一个核心问题：**整个 RAG 系统（检索 + 生成）作为一个整体，表现如何？**

---

### 3.1 LLMJudge（LLM 当裁判）

#### 概念说明

用一个独立的 LLM（Judge LLM）作为裁判，综合评估整个 RAG pipeline 的输出质量。它同时考虑检索相关性、回答准确性、完整性等多个维度。

#### 评估维度

| 维度 | 说明 |
|------|------|
| 检索相关性 | 检索到的资料是否与问题相关 |
| 回答准确性 | 回答是否事实正确 |
| 完整性 | 是否覆盖了问题的所有方面 |
| 忠实度 | 回答是否基于检索资料，无幻觉 |
| 有用性 | 对用户是否有实际帮助 |

#### 类定义

```typescript
/** 端到端 LLM 裁判结果 */
interface E2EJudgeResult {
  /** 各维度得分 */
  scores: Record<string, number>;
  /** 综合得分（各维度加权平均） */
  overallScore: number;
  /** 详细反馈 */
  feedback: string;
}

interface E2ELLMJudgeOptions {
  /** 裁判 LLM */
  judgeLLM: LLMProvider;
  /** 评估维度列表 */
  dimensions?: string[];
}

class E2ELLMJudge {
  private readonly judgeLLM: LLMProvider;
  private readonly dimensions: string[];

  constructor(options: E2ELLMJudgeOptions) {
    this.judgeLLM = options.judgeLLM;
    this.dimensions = options.dimensions ?? [
      '检索相关性',
      '回答准确性',
      '完整性',
      '忠实度',
      '有用性',
    ];
  }

  /**
   * 综合评估一次 RAG 交互
   * @param query 用户问题
   * @param answer 系统回答
   * @param context 检索到的参考资料
   */
  async judge(
    query: string,
    answer: string,
    context: string[],
  ): Promise<E2EJudgeResult> {
    const contextStr = context.join('\n---\n');
    const dimensionsStr = this.dimensions.map((d) => `- ${d}`).join('\n');

    const prompt = `你是一个 RAG 系统的评审员。请从以下维度综合评估系统的表现。

## 用户问题
${query}

## 检索到的资料
${contextStr}

## 系统回答
${answer}

## 评估维度
${dimensionsStr}

## 要求
请为每个维度打 1-10 分，并给出综合评语。以 JSON 格式返回：
{
  "scores": {
    "维度名": 分数(1-10)
  },
  "overallScore": 综合分(1-10),
  "feedback": "综合评语，指出优点和改进建议"
}`;

    const response = await this.judgeLLM.chat(
      [
        {
          role: 'system',
          content: '你是一个专业的 RAG 系统评审员，请客观、严格地评估。',
        },
        { role: 'user', content: prompt },
      ],
      { temperature: 0, responseFormat: 'json' },
    );

    const result = JSON.parse(response) as E2EJudgeResult;

    // 确保分数在 1-10 范围内
    for (const key of Object.keys(result.scores)) {
      result.scores[key] = Math.min(10, Math.max(1, result.scores[key]));
    }
    result.overallScore = Math.min(10, Math.max(1, result.overallScore));

    return result;
  }
}
```

#### 使用示例


### 3.2 ABTest（A/B 测试分析）

#### 概念说明

A/B 测试通过**对比两个版本的 RAG 系统在真实用户上的表现**，判断哪个版本更好。核心是基于用户行为数据（点赞、追问、点击引用、停留时间）进行统计显著性检验。

#### 用户行为指标

| 行为 | 含义 | 正向/负向 |
|------|------|-----------|
| 点赞 (thumbsUp) | 用户认为回答有帮助 | 正向 |
| 追问 (followUp) | 用户对回答不满意，继续追问 | 负向 |
| 点击引用 (sourceClicked) | 用户对检索来源感兴趣 | 正向 |
| 停留时间 (dwellTime) | 用户阅读回答的时间 | 正向（适度范围内） |

#### 类定义

```typescript
/** A/B 测试事件 */
interface ABTestEvent {
  /** 变体标识 */
  variant: 'A' | 'B';
  /** 用户问题 */
  query: string;
  /** 用户是否点赞 */
  thumbsUp?: boolean;
  /** 用户是否追问 */
  followUp?: boolean;
  /** 用户是否点击了引用来源 */
  sourceClicked?: boolean;
  /** 用户停留时间（秒） */
  dwellTime?: number;
}

/** A/B 测试报告 */
interface ABTestReport {
  /** 各变体的指标统计 */
  metrics: Record<
    'A' | 'B',
    {
      totalEvents: number;
      thumbsUpRate: number;
      followUpRate: number;
      sourceClickRate: number;
      avgDwellTime: number;
      satisfactionScore: number;
    }
  >;
  /** Z 检验结果 */
  zTest: {
    zScore: number;
    pValue: number;
    significant: boolean;
    confidenceLevel: number;
  };
  /** 获胜方 */
  winner: 'A' | 'B' | '无显著差异';
}

class ABTestAnalyzer {
  private readonly events: ABTestEvent[] = [];
  private readonly confidenceLevel: number;

  constructor(confidenceLevel: number = 0.95) {
    this.confidenceLevel = confidenceLevel;
  }

  /** 收集一个用户行为事件 */
  collectEvent(event: ABTestEvent): void {
    this.events.push(event);
  }

  /** 批量收集事件 */
  collectEvents(events: ABTestEvent[]): void {
    this.events.push(...events);
  }

  /** 分析 A/B 测试结果 */
  async analyze(): Promise<ABTestReport> {
    const eventsA = this.events.filter((e) => e.variant === 'A');
    const eventsB = this.events.filter((e) => e.variant === 'B');

    const metricsA = this.computeMetrics(eventsA);
    const metricsB = this.computeMetrics(eventsB);

    // 用满意度分数做 Z 检验
    const zTest = this.zTest(
      metricsA.satisfactionScore,
      metricsA.totalEvents,
      metricsB.satisfactionScore,
      metricsB.totalEvents,
    );

    let winner: 'A' | 'B' | '无显著差异';
    if (!zTest.significant) {
      winner = '无显著差异';
    } else {
      winner =
        metricsA.satisfactionScore > metricsB.satisfactionScore ? 'A' : 'B';
    }

    return {
      metrics: { A: metricsA, B: metricsB },
      zTest,
      winner,
    };
  }

  private computeMetrics(events: ABTestEvent[]) {
    const total = events.length;
    if (total === 0) {
      return {
        totalEvents: 0,
        thumbsUpRate: 0,
        followUpRate: 0,
        sourceClickRate: 0,
        avgDwellTime: 0,
        satisfactionScore: 0,
      };
    }

    const thumbsUp = events.filter((e) => e.thumbsUp === true).length;
    const followUp = events.filter((e) => e.followUp === true).length;
    const sourceClicked = events.filter((e) => e.sourceClicked === true).length;
    const dwellTimes = events
      .map((e) => e.dwellTime)
      .filter((t): t is number => t !== undefined);
    const avgDwell =
      dwellTimes.length > 0
        ? dwellTimes.reduce((a, b) => a + b, 0) / dwellTimes.length
        : 0;

    // 综合满意度分数：点赞(+) - 追问(-) + 引用点击(+) + 适度停留时间(+)
    const thumbsUpRate = thumbsUp / total;
    const followUpRate = followUp / total;
    const sourceClickRate = sourceClicked / total;

    const satisfactionScore =
      thumbsUpRate * 0.4 -
      followUpRate * 0.3 +
      sourceClickRate * 0.15 +
      Math.min(avgDwell / 60, 1) * 0.15;

    return {
      totalEvents: total,
      thumbsUpRate,
      followUpRate,
      sourceClickRate,
      avgDwellTime: avgDwell,
      satisfactionScore,
    };
  }

  /**
   * Z 检验（双样本比例检验）
   * 用于判断两个变体的差异是否具有统计显著性
   */
  private zTest(
    scoreA: number,
    nA: number,
    scoreB: number,
    nB: number,
  ): ABTestReport['zTest'] {
    if (nA === 0 || nB === 0) {
      return { zScore: 0, pValue: 1, significant: false, confidenceLevel: this.confidenceLevel };
    }

    // 简化的 Z 检验：将满意度视为比例
    const pA = Math.max(0, Math.min(1, scoreA));
    const pB = Math.max(0, Math.min(1, scoreB));
    const pPooled = (pA * nA + pB * nB) / (nA + nB);
    const se = Math.sqrt(pPooled * (1 - pPooled) * (1 / nA + 1 / nB));

    const zScore = se === 0 ? 0 : (pA - pB) / se;

    // 近似 p-value（使用标准正态分布的近似）
    const pValue = 2 * (1 - this.normalCDF(Math.abs(zScore)));

    return {
      zScore,
      pValue,
      significant: pValue < 1 - this.confidenceLevel,
      confidenceLevel: this.confidenceLevel,
    };
  }

  /** 标准正态分布 CDF 近似 */
  private normalCDF(x: number): number {
    // Abramowitz and Stegun 近似公式
    const a1 = 0.254829592;
    const a2 = -0.284496736;
    const a3 = 1.421413741;
    const a4 = -1.453152027;
    const a5 = 1.061405429;
    const p = 0.3275911;

    const sign = x < 0 ? -1 : 1;
    const absX = Math.abs(x);
    const t = 1 / (1 + p * absX);
    const y =
      1 - ((((a5 * t + a4) * t + a3) * t + a2) * t + a1) * t * Math.exp(-absX * absX / 2);

    return 0.5 * (1 + sign * y);
  }
}
```

### 3.3 评测报告生成器 (EvaluationReport)

#### 概念说明

将检索评测、生成评测、端到端评测的结果汇总为一份完整的结构化报告，方便对比和归档。

#### 类定义

```typescript
/** 完整评测报告 */
interface FullReport {
  /** 报告生成时间 */
  timestamp: string;
  /** 评测概要 */
  summary: {
    totalQueries: number;
    overallScore: number;
    verdict: string;
  };
  /** 检索评测结果 */
  retrieval: {
    metrics: Record<string, number>;
    perQuery?: Array<Record<string, number>>;
  };
  /** 生成评测结果 */
  generation: {
    metrics: Record<string, number>;
    perItem?: Array<Record<string, number>>;
  };
  /** 端到端评测结果 */
  e2e: {
    llmJudgeScores?: Record<string, number>;
    abTest?: ABTestReport;
  };
  /** 建议与改进方向 */
  recommendations: string[];
}

class EvaluationReport {
  private retrievalReport?: BenchmarkReport;
  private generationReport?: GenerationReport;
  private e2eJudgeResults?: E2EJudgeResult[];
  private abTestReport?: ABTestReport;

  /** 设置检索评测报告 */
  setRetrievalReport(report: BenchmarkReport): void {
    this.retrievalReport = report;
  }

  /** 设置生成评测报告 */
  setGenerationReport(report: GenerationReport): void {
    this.generationReport = report;
  }

  /** 设置端到端 LLM Judge 结果 */
  setE2EJudgeResults(results: E2EJudgeResult[]): void {
    this.e2eJudgeResults = results;
  }

  /** 设置 A/B 测试报告 */
  setABTestReport(report: ABTestReport): void {
    this.abTestReport = report;
  }

  /** 生成完整的评测报告 */
  async generateReport(): Promise<FullReport> {
    const report: FullReport = {
      timestamp: new Date().toISOString(),
      summary: {
        totalQueries: 0,
        overallScore: 0,
        verdict: '',
      },
      retrieval: { metrics: {} },
      generation: { metrics: {} },
      e2e: {},
      recommendations: [],
    };

    // 汇总检索评测
    if (this.retrievalReport) {
      report.retrieval = {
        metrics: this.retrievalReport.metrics,
        perQuery: this.retrievalReport.perQuery,
      };
      report.summary.totalQueries = this.retrievalReport.totalQueries;
    }

    // 汇总生成评测
    if (this.generationReport) {
      report.generation = {
        metrics: this.generationReport.metrics,
        perItem: this.generationReport.perItem,
      };
      if (report.summary.totalQueries === 0) {
        report.summary.totalQueries = this.generationReport.totalItems;
      }
    }

    // 汇总端到端评测
    if (this.e2eJudgeResults && this.e2eJudgeResults.length > 0) {
      const avgScores: Record<string, number> = {};
      const dimensions = Object.keys(this.e2eJudgeResults[0].scores);
      for (const dim of dimensions) {
        const scores = this.e2eJudgeResults.map((r) => r.scores[dim]);
        avgScores[dim] = scores.reduce((a, b) => a + b, 0) / scores.length;
      }
      report.e2e.llmJudgeScores = avgScores;
    }

    if (this.abTestReport) {
      report.e2e.abTest = this.abTestReport;
    }

    // 计算综合分数
    const allScores = [
      ...Object.values(report.retrieval.metrics),
      ...Object.values(report.generation.metrics),
    ];
    if (report.e2e.llmJudgeScores) {
      allScores.push(...Object.values(report.e2e.llmJudgeScores).map((s) => s / 10));
    }
    report.summary.overallScore =
      allScores.length > 0
        ? allScores.reduce((a, b) => a + b, 0) / allScores.length
        : 0;

    // 生成评估结论
    report.summary.verdict = this.generateVerdict(report.summary.overallScore);

    // 生成改进建议
    report.recommendations = this.generateRecommendations(report);

    return report;
  }

  private generateVerdict(score: number): string {
    if (score >= 0.9) return '优秀：系统表现优异，可投入生产';
    if (score >= 0.7) return '良好：系统表现良好，有优化空间';
    if (score >= 0.5) return '一般：系统基本可用，需要重点优化';
    return '较差：系统表现不佳，建议大幅改进后重新评测';
  }

  private generateRecommendations(report: FullReport): string[] {
    const recommendations: string[] = [];

    // 基于检索指标给建议
    const recall = report.retrieval.metrics['Recall@K'];
    if (recall !== undefined && recall < 0.7) {
      recommendations.push('召回率偏低，建议：增加文档覆盖范围、优化 Embedding 模型、调整 chunk 策略');
    }

    const precision = report.retrieval.metrics['Precision@K'];
    if (precision !== undefined && precision < 0.6) {
      recommendations.push('精确率偏低，建议：优化排序算法、引入重排序（reranking）机制');
    }

    // 基于生成指标给建议
    const faithfulness = report.generation.metrics['Faithfulness'];
    if (faithfulness !== undefined && faithfulness < 0.8) {
      recommendations.push('忠实度偏低（存在幻觉），建议：加强 prompt 约束、引入引用标注机制');
    }

    const relevance = report.generation.metrics['AnswerRelevance'];
    if (relevance !== undefined && relevance < 0.7) {
      recommendations.push('答案相关性偏低，建议：优化生成 prompt、增加对问题的理解');
    }

    if (recommendations.length === 0) {
      recommendations.push('各指标表现良好，建议持续监控并扩大评测数据集');
    }

    return recommendations;
  }
}
```
