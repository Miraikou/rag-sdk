## 快速开始

如果你是第一次参与这个项目，建议按以下顺序阅读：
1. [01-项目概述](./01-项目概述.md) → 理解项目是什么
2. [02-架构设计](./02-架构设计.md) → 理解怎么组织
3. [03-核心接口](./03-核心接口.md) → 理解核心抽象
4. 按需阅读各模块文档

## 使用方式

这套文档作为 **vibe coding** 的上下文使用：
- 开始编码前，将相关文档喂给 AI 助手作为 context
- 每个模块文档包含：概念说明、接口定义、实现要求、代码示例
- 按照 [02-架构设计](./02-架构设计.md) 中的实施阶段逐步推进
