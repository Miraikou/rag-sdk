# 项目概述

## 1. 项目名称

**RAG SDK** —— TypeScript 通用 RAG 框架

## 2. 项目目标

构建一个通用、模块化、可扩展的 RAG SDK（类似 TypeScript 版 LangChain），提供完整的 RAG pipeline 和各种优化策略。

核心目标：
- 提供开箱即用的 RAG pipeline，5 分钟即可完成基础搭建
- 每个模块可独立使用、独立替换，不产生耦合锁定
- 内置多种经过验证的 RAG 优化策略（语义切块、混合检索、重排序、引用生成等）
- 通过 adapter 模式对接任意 LLM 提供商和向量数据库
- 完善的评测体系，支持对不同策略进行量化对比

## 3. 核心设计理念

### 3.1 接口驱动

每个模块定义抽象接口，用户可自定义实现。所有接口均使用 TypeScript 泛型，确保类型安全。

```ts
// 示例：LLM 接口定义
interface LLM<TOptions = Record<string, unknown>> {
  generate(prompt: string, options?: TOptions): Promise<string>;
  stream(prompt: string, options?: TOptions): AsyncIterable<string>;
}

// 用户自定义实现
class MyCustomLLM implements LLM<{ temperature: number }> {
  async generate(prompt: string, options?: { temperature: number }): Promise<string> {
    // 自定义实现
  }
  async *stream(prompt: string, options?: { temperature: number }): AsyncIterable<string> {
    // 自定义流式实现
  }
}
```

### 3.2 Pipeline 模式

通过管道组合各阶段，支持灵活编排。Pipeline 由一系列可组合的 Stage 构成，每个 Stage 可独立配置和替换。

```ts
// Pipeline 支持链式调用和声明式配置两种方式
const pipeline = new RAGPipeline()
  .addStage(new IngestionStage({ chunker, embedding, store }))
  .addStage(new RetrievalStage({ retriever, postProcessors }))
  .addStage(new GenerationStage({ generator }));
```

### 3.3 策略模式

切块、检索、生成等均可替换策略，通过构造函数注入即可切换：

```ts
// 切换不同的切块策略
const chunker1 = new RecursiveChunker({ chunkSize: 500 });
const chunker2 = new SemanticChunker({ similarityThreshold: 0.7 });

// 切换不同的检索策略
const retriever1 = new VectorRetriever({ topK: 10 });
const retriever2 = new FusionRetriever({ topK: 10, weights: [0.6, 0.4] });
```

### 3.4 零侵入

不强制依赖特定 LLM 或向量数据库。核心包 `@rag-sdk/core` 零运行时依赖，所有外部集成通过 adapter 包提供：

- LLM：通过 `@rag-sdk/llm` 提供 OpenAI、Anthropic 等适配器
- 向量库：通过 `@rag-sdk/storage` 提供 Chroma、Pinecone、Qdrant 等适配器
- 用户可只安装需要的 adapter，不引入多余的依赖

## 5. 目标用户

### 5.1 需要构建 RAG 应用的开发者

- 快速搭建企业知识库、智能客服等 RAG 应用
- 通过模块化设计，按需引入所需组件
- 丰富的配置选项，平衡易用性和灵活性

### 5.2 需要对比不同 RAG 策略效果的研究者

- 内置多种前沿 RAG 策略（语义切块、HyDE、Self-RAG 等）
- 评测模块支持对检索和生成质量进行量化评估
- 方便进行 A/B 测试和策略对比实验

### 5.3 企业内部知识库系统的后端开发

- 支持增量更新，无需每次全量重建索引
- 提供知识图谱增强能力，处理实体关系查询
- 流式输出支持，优化用户体验

## 6. 使用示例

以下代码展示了 RAG SDK 的目标 API 形态：

```ts
import { RAGPipeline } from '@rag-sdk';
import { OpenAI, OpenAIEmbedding } from '@rag-sdk/llm';
import { MemoryStore } from '@rag-sdk/storage';
import { SemanticChunker } from '@rag-sdk/document';
import { FusionRetriever, Reranker } from '@rag-sdk/retrieval';
import { CitationGenerator } from '@rag-sdk/generation';

// 初始化 RAG Pipeline
const rag = new RAGPipeline({
  llm: new OpenAI({ apiKey: process.env.OPENAI_API_KEY }),
  embedding: new OpenAIEmbedding({ apiKey: process.env.OPENAI_API_KEY }),
  store: new MemoryStore(),
  chunker: new SemanticChunker(),
  retriever: new FusionRetriever(),
  postProcessors: [new Reranker()],
  generator: new CitationGenerator(),
});

// 导入文档（支持批量导入）
await rag.ingest([
  {
    content: '公司年假为15天，工龄满5年可额外获得3天年假...',
    metadata: { source: '员工手册', department: 'HR' },
  },
  {
    content: '项目奖金按季度发放，金额为月薪的1-3倍...',
    metadata: { source: '薪酬制度', department: 'Finance' },
  },
]);

// 查询（返回答案和引用来源）
const { answer, sources } = await rag.query('年假有几天？');
// answer: "根据公司员工手册，年假为15天，工龄满5年可额外获得3天。"
// sources: [{ content: '公司年假为15天...', metadata: { source: '员工手册' }, score: 0.92 }]

// 流式查询
for await (const chunk of rag.streamQuery('项目奖金怎么计算？')) {
  process.stdout.write(chunk); // 实时输出
}
```

### 进阶用法示例

```ts
import { RAGPipeline } from '@rag-sdk';
import { HyDEQueryTransformer } from '@rag-sdk/retrieval';
import { SelfRAGGenerator } from '@rag-sdk/generation';
import { GraphStore, GraphRetriever } from '@rag-sdk/knowledge-graph';

// 使用高级策略
const advancedRag = new RAGPipeline({
  llm: new OpenAI({ model: 'gpt-4' }),
  embedding: new OpenAIEmbedding(),
  store: new ChromaStore({ collection: 'docs' }),
  chunker: new SemanticChunker({ similarityThreshold: 0.75 }),
  queryTransformer: new HyDEQueryTransformer(), // HyDE 查询变换
  retriever: new FusionRetriever({
    strategies: [
      new VectorRetriever({ topK: 20 }),
      new GraphRetriever({ depth: 2 }),       // 知识图谱检索
    ],
    topK: 10,
  }),
  postProcessors: [
    new Reranker({ model: 'cohere-rerank-v3' }),
    new RedundancyFilter({ threshold: 0.85 }),  // 去重过滤
  ],
  generator: new SelfRAGGenerator(),            // Self-RAG 自反思生成
  graphStore: new GraphStore(),                 // 知识图谱存储
});
```
