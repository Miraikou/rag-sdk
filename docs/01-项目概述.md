# 项目概述

## 1. 项目名称

**RAG SDK** —— TypeScript 通用 RAG 框架

## 2. 项目目标

构建一个通用、模块化、可扩展的 RAG SDK（类似 TypeScript 版 LangChain），提供完整的 RAG pipeline 和各种优化策略。

核心目标：
- 提供开箱即用的 RAG pipeline，5 分钟即可完成基础搭建
- 每个模块可独立使用、独立替换，不产生耦合锁定
- 内置多种经过验证的 RAG 优化策略（语义切块、混合检索、重排序、引用生成等）
- 通过 adapter 模式对接任意 LLM 提供商和向量数据库
- 完善的评测体系，支持对不同策略进行量化对比

## 3. 核心设计理念

### 3.1 接口驱动

每个模块定义抽象接口，用户可自定义实现。所有接口定义在 `packages/core/src/types.ts` 中，完整签名请参考源码 JSDoc。

核心接口包括：
- `LLMProvider` — LLM 对话（`chat`、`chatStream`、`chatJson`）
- `EmbeddingProvider` — 向量嵌入（`embed`、`embedBatch`）
- `VectorStore` — 向量存储（`upsert`、`search`、`delete`）
- `Retriever` — 检索器（`retrieve`）
- `Generator` — 答案生成器（`generate`、`generateStream?`）
- `PostProcessor` — 后处理器（`process`）
- `Chunker` — 切块策略（`chunk`）
- `QueryTransformer` — 查询变换（`transform`）

用户可实现任意接口来自定义行为，详见 `docs/03-核心接口.md`。

### 3.2 Pipeline 模式

通过管道组合各阶段，支持灵活编排。`RAGPipeline` 串联 变换 → 检索 → 后处理 → 生成 四阶段，支持同步和流式查询。

```ts
// 使用预设快速创建
const rag = await createSimpleRAG({ llm, embedding, store });

// 或使用 PipelineBuilder 精细控制
const rag = new PipelineBuilder()
  .setLLM(llm)
  .setEmbedding(embedding)
  .setStore(store)
  .setChunker(new FixedSizeChunker({ chunkSize: 500 }))
  .addQueryTransformer(new QueryRewriter(llm))
  .setRetriever(new FusionSearch(vectorSearch, keywordSearch))
  .addPostProcessor(new RerankerPostProcessor(scorer))
  .setMonitor(new LoggingMonitor())
  .build();
```

### 3.3 策略模式

切块、检索、生成等均可替换策略，通过构造函数注入即可切换：

```ts
// 切换不同的切块策略
const chunker1 = new FixedSizeChunker({ chunkSize: 500, overlap: 50 });
const chunker2 = new SemanticChunker({ similarityThreshold: 0.7 });
const chunker3 = new MarkdownChunker({ headingLevel: 2 });

// 切换不同的检索策略
const retriever1 = new VectorSearch(embedding, store);
const retriever2 = new FusionSearch(vectorSearch, keywordSearch, 0.7, 0.3);
const retriever3 = new RRFSearch(60); // RRF 融合

// 切换不同的后处理器
const post1 = new ThresholdPostProcessor({ threshold: 0.5 });
const post2 = new RerankerPostProcessor(scorer, { topK: 5 });
```

### 3.4 零侵入

不强制依赖特定 LLM 或向量数据库。核心包 `@ragsdk/core` 零运行时依赖，所有外部集成通过 adapter 包提供：

- LLM：通过 `@ragsdk/llm` 提供 OpenAI 适配器（Anthropic、Google 适配器待实现）
- 向量库：通过 `@ragsdk/storage` 提供 MemoryStore 内存存储（Pinecone、Chroma、Qdrant、Weaviate 适配器待实现）
- 用户可只安装需要的 adapter，不引入多余的依赖

## 5. 目标用户

### 5.1 需要构建 RAG 应用的开发者

- 快速搭建企业知识库、智能客服等 RAG 应用
- 通过模块化设计，按需引入所需组件
- 丰富的配置选项，平衡易用性和灵活性

### 5.2 需要对比不同 RAG 策略效果的研究者

- 内置多种前沿 RAG 策略（语义切块、HyDE、Self-RAG 等）
- 评测模块支持对检索和生成质量进行量化评估
- 方便进行 A/B 测试和策略对比实验

### 5.3 企业内部知识库系统的后端开发

- 支持增量更新，无需每次全量重建索引
- 提供知识图谱增强能力，处理实体关系查询
- 流式输出支持，优化用户体验

## 6. 使用示例

以下代码展示了 RAG SDK 的实际 API（类名和导入路径与源码一致）：

```ts
import { createSimpleRAG } from 'rag-sdk';
import { OpenAIProvider } from '@ragsdk/llm';
import { OpenAIEmbeddingProvider } from '@ragsdk/embedding';
import { MemoryStore } from '@ragsdk/storage';

// 一行创建基础 RAG Pipeline
const rag = await createSimpleRAG({
  llm: new OpenAIProvider({ apiKey: process.env.OPENAI_API_KEY }),
  embedding: new OpenAIEmbeddingProvider({ apiKey: process.env.OPENAI_API_KEY }),
  store: new MemoryStore(),
  topK: 5,
});

// 导入文档
await rag.ingest([
  {
    id: 'doc-1',
    content: '公司年假为15天，工龄满5年可额外获得3天年假...',
    metadata: { source: '员工手册', department: 'HR' },
  },
]);

// 查询（返回答案和引用来源）
const { answer, sources } = await rag.query('年假有几天？');

// 流式查询（使用 LLM 的流式 API，真正的逐 token 输出）
for await (const chunk of rag.queryStream('项目奖金怎么计算？')) {
  process.stdout.write(chunk);
}
```

### 进阶用法示例

```ts
import { createAdvancedRAG, PipelineBuilder } from 'rag-sdk';
import { OpenAIProvider } from '@ragsdk/llm';
import { OpenAIEmbeddingProvider } from '@ragsdk/embedding';
import { MemoryStore } from '@ragsdk/storage';
import { LoggingMonitor } from '@ragsdk/core';

// 方式一：Advanced RAG 预设（查询改写 + 混合检索 + 重排序）
const advancedRag = await createAdvancedRAG({
  llm: new OpenAIProvider({ apiKey: process.env.OPENAI_API_KEY }),
  embedding: new OpenAIEmbeddingProvider({ apiKey: process.env.OPENAI_API_KEY }),
  store: new MemoryStore(),
  rerankerScorer: async (query, content) => crossEncoderScore(query, content),
});

// 方式二：PipelineBuilder 精细控制
const customRag = new PipelineBuilder()
  .setLLM(new OpenAIProvider({ apiKey: process.env.OPENAI_API_KEY }))
  .setEmbedding(new OpenAIEmbeddingProvider({ apiKey: process.env.OPENAI_API_KEY }))
  .setStore(new MemoryStore())
  .setChunker(new FixedSizeChunker({ chunkSize: 500 }))
  .addQueryTransformer(new HyDETransformer(llm))
  .setMonitor(new LoggingMonitor())
  .build();
```

> 更多用法请参考各模块源码中的 JSDoc 注释。
