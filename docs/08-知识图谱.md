# 知识图谱模块

> 知识图谱将文档中的实体和关系抽取出来构建图结构，弥补向量检索无法进行多步推理的不足，为 RAG 系统提供结构化的知识检索能力。

---

## 一、概述

### 1.1 什么是知识图谱

知识图谱（Knowledge Graph）是一种**用图结构表示实体及其关系**的数据模型。在 RAG 系统中，它把非结构化文档中的知识抽取为结构化的三元组（实体-关系-实体），形成一张语义网络。

### 1.2 解决什么问题

传统向量检索只能找到与 query **语义相似**的文档段落，但无法处理需要**多步推理**的问题：

| 场景 | 向量检索 | 知识图谱 |
|------|----------|----------|
| "A 公司的 CEO 是谁？" | 能找到包含该信息的段落 | 直接返回关系 |
| "A 公司 CEO 毕业于哪所大学？" | 需要两段信息拼接，难以完成 | A → CEO → 人 → 毕业 → 大学 |
| "哪些公司使用了 X 技术？" | 可能遗漏间接关联 | 沿关系链遍历，不遗漏 |

### 1.3 适用场景

- 需要回答实体关系的问题（"谁管理谁"、"属于哪个部门"）
- 多跳推理（A→B→C 链条式问题）
- 需要全局视角的查询（"公司所有项目的技术栈"）
- 需要结合向量检索做混合检索的场景

## 二、实体关系抽取 (EntityExtractor)

### 2.1 概念说明

实体关系抽取是知识图谱构建的第一步：用 LLM 从非结构化文档中**自动提取实体和关系**，输出结构化的图数据。

### 2.2 核心概念

- **实体 (Entity)**：文档中提到的具体事物，如人物、组织、产品、地点、概念等
- **关系 (Relation)**：实体之间的联系，如"管理"、"属于"、"依赖"、"位于"等
- **三元组**：`(源实体, 关系, 目标实体)` — 知识图谱的基本单元

### 2.3 接口定义

```typescript
/** 文档输入 */
```

### 2.4 EntityExtractor 类定义

```typescript
interface EntityExtractorOptions {
  /** LLM 提供者 */
  llmProvider: LLMProvider;
  /** 需要提取的实体类型列表 */
  entityTypes?: string[];
  /** 需要提取的关系类型列表 */
  relationTypes?: string[];
  /** 自定义抽取 prompt（覆盖默认） */
  extractPrompt?: string;
}

class EntityExtractor {
  private readonly llmProvider: LLMProvider;
  private readonly entityTypes: string[];
  private readonly relationTypes: string[];
  private readonly extractPrompt?: string;

  constructor(options: EntityExtractorOptions) {
    this.llmProvider = options.llmProvider;
    this.entityTypes = options.entityTypes ?? [
      '人物',
      '组织',
      '产品',
      '地点',
      '概念',
      '技术',
      '事件',
    ];
    this.relationTypes = options.relationTypes ?? [
      '管理',
      '属于',
      '依赖',
      '位于',
      '创建',
      '使用',
      '包含',
    ];
    this.extractPrompt = options.extractPrompt;
  }

  /**
   * 从文档中抽取实体和关系
   * @param document 输入文档
   * @returns 抽取的图数据
   */
  async extract(document: Document): Promise<GraphData> {
    const entityTypesStr = this.entityTypes.join('、');
    const relationTypesStr = this.relationTypes.join('、');

    const prompt =
      this.extractPrompt ??
      `你是一个知识图谱构建专家。请从以下文档中提取实体和关系。

## 文档内容
${document.content}

## 实体类型
${entityTypesStr}

## 关系类型
${relationTypesStr}

## 要求
1. 提取所有符合上述类型的实体
2. 提取实体之间的关系
3. 实体名称要标准化（如"苹果公司"和"Apple Inc."统一为一个名称）
4. 以 JSON 格式返回：
{
  "entities": [
    {
      "name": "实体名称",
      "type": "实体类型",
      "metadata": { "原文": "原文中的表述" }
    }
  ],
  "relations": [
    {
      "source": "源实体名称",
      "target": "目标实体名称",
      "type": "关系类型",
      "metadata": { "原文": "原文中的表述" }
    }
  ]
}`;

    const response = await this.llmProvider.chat(
      [
        {
          role: 'system',
          content: '你是一个知识图谱构建专家，精确地从文本中提取实体和关系。',
        },
        { role: 'user', content: prompt },
      ],
      { temperature: 0, responseFormat: 'json' },
    );

    const parsed = JSON.parse(response) as {
      entities: Array<{ name: string; type: string; metadata: Record<string, unknown> }>;
      relations: Array<{
        source: string;
        target: string;
        type: string;
        metadata: Record<string, unknown>;
      }>;
    };

    // 为实体生成唯一 ID
    const entityMap = new Map<string, string>();
    const entities: Entity[] = parsed.entities.map((e, index) => {
      const id = this.generateEntityId(e.name, document.id, index);
      entityMap.set(e.name, id);
      return {
        id,
        name: e.name,
        type: e.type,
        metadata: {
          ...e.metadata,
          sourceDocumentId: document.id,
        },
      };
    });

    // 解析关系，使用实体 ID 替代名称
    const relations: Relation[] = parsed.relations
      .filter((r) => entityMap.has(r.source) && entityMap.has(r.target))
      .map((r) => ({
        source: entityMap.get(r.source)!,
        target: entityMap.get(r.target)!,
        type: r.type,
        metadata: {
          ...r.metadata,
          sourceDocumentId: document.id,
        },
      }));

    return { entities, relations };
  }

  /**
   * 生成实体唯一 ID
   * 基于实体名称的规范化哈希，确保同名实体在不同文档中获得相同 ID
   */
  private generateEntityId(
    name: string,
    _documentId: string,
    _index: number,
  ): string {
    // 规范化名称：去除空格、转小写
    const normalized = name.trim().toLowerCase().replace(/\s+/g, '_');
    return `entity_${normalized}`;
  }
}
```

## 三、图存储 (GraphStore)

### 3.1 概念说明

GraphStore 是存储和查询图数据的抽象层。它定义了图操作的统一接口，支持多种底层实现（内存、数据库等），使得上层业务代码不依赖具体的存储引擎。

### 3.2 接口定义

```typescript
/** 邻居查询结果 */
interface NeighborResult {
  /** 邻居实体列表 */
  entities: Entity[];
  /** 连接到邻居的关系列表 */
  relations: Relation[];
}

/** 邻居查询选项 */
interface NeighborOptions {
  /** 关系类型过滤 */
  relationTypes?: string[];
  /** 实体类型过滤 */
  entityTypes?: string[];
  /** 跳数限制，默认 1 */
  hops?: number;
  /** 最大返回数量 */
  limit?: number;
}

/** 图查询结果 */
interface GraphQueryResult {
  /** 匹配的实体列表 */
  entities: Entity[];
  /** 匹配的关系列表 */
  relations: Relation[];
  /** 匹配的路径列表（每条路径是实体序列） */
  paths: Entity[][];
}

/** 图存储接口 */
interface GraphStore {
  /** 批量添加实体 */
  addEntities(entities: Entity[]): Promise<void>;

  /** 批量添加关系 */
  addRelations(relations: Relation[]): Promise<void>;

  /** 根据 ID 获取实体 */
  getEntity(entityId: string): Promise<Entity | null>;

  /** 获取实体的邻居 */
  getNeighbors(entityId: string, options?: NeighborOptions): Promise<NeighborResult>;

  /** 查找两个实体之间的路径 */
  findPath(sourceId: string, targetId: string): Promise<Entity[]>;

  /** 自然语言图查询 */
  query(query: string): Promise<GraphQueryResult>;
}
```

### 3.3 MemoryGraphStore（内存图存储）

基于邻接表的内存图存储实现，适用于开发调试和中小规模数据。

```typescript
class MemoryGraphStore implements GraphStore {
  /** 实体存储：entityId → Entity */
  private readonly entities = new Map<string, Entity>();

  /** 邻接表：entityId → 出边列表 */
  private readonly outgoingEdges = new Map<string, Relation[]>();

  /** 反向邻接表：entityId → 入边列表 */
  private readonly incomingEdges = new Map<string, Relation[]>();

  async addEntities(entities: Entity[]): Promise<void> {
    for (const entity of entities) {
      // 如果实体已存在，合并元数据
      const existing = this.entities.get(entity.id);
      if (existing) {
        existing.metadata = { ...existing.metadata, ...entity.metadata };
      } else {
        this.entities.set(entity.id, { ...entity });
      }
    }
  }

  async addRelations(relations: Relation[]): Promise<void> {
    for (const relation of relations) {
      // 添加到出边
      const outEdges = this.outgoingEdges.get(relation.source) ?? [];
      // 去重：同 source + target + type 视为重复
      const isDuplicate = outEdges.some(
        (e) =>
          e.target === relation.target &&
          e.type === relation.type,
      );
      if (!isDuplicate) {
        outEdges.push({ ...relation });
        this.outgoingEdges.set(relation.source, outEdges);
      }

      // 添加到入边
      const inEdges = this.incomingEdges.get(relation.target) ?? [];
      if (!isDuplicate) {
        inEdges.push({ ...relation });
        this.incomingEdges.set(relation.target, inEdges);
      }
    }
  }

  async getEntity(entityId: string): Promise<Entity | null> {
    return this.entities.get(entityId) ?? null;
  }

  async getNeighbors(
    entityId: string,
    options?: NeighborOptions,
  ): Promise<NeighborResult> {
    const hops = options?.hops ?? 1;
    const limit = options?.limit ?? Infinity;

    const visitedEntities = new Set<string>();
    const collectedEntities: Entity[] = [];
    const collectedRelations: Relation[] = [];

    // BFS 遍历
    let currentLevel = [entityId];
    visitedEntities.add(entityId);

    for (let hop = 0; hop < hops; hop++) {
      const nextLevel: string[] = [];

      for (const id of currentLevel) {
        // 收集出边
        const outEdges = this.outgoingEdges.get(id) ?? [];
        // 收集入边（双向遍历）
        const inEdges = this.incomingEdges.get(id) ?? [];
        const allEdges = [...outEdges, ...inEdges];

        for (const edge of allEdges) {
          // 应用关系类型过滤
          if (
            options?.relationTypes &&
            !options.relationTypes.includes(edge.type)
          ) {
            continue;
          }

          const neighborId =
            edge.source === id ? edge.target : edge.source;

          if (visitedEntities.has(neighborId)) continue;

          const neighborEntity = this.entities.get(neighborId);
          if (!neighborEntity) continue;

          // 应用实体类型过滤
          if (
            options?.entityTypes &&
            !options.entityTypes.includes(neighborEntity.type)
          ) {
            continue;
          }

          visitedEntities.add(neighborId);
          collectedEntities.push(neighborEntity);
          collectedRelations.push(edge);
          nextLevel.push(neighborId);

          if (collectedEntities.length >= limit) {
            return {
              entities: collectedEntities,
              relations: collectedRelations,
            };
          }
        }
      }

      currentLevel = nextLevel;
    }

    return { entities: collectedEntities, relations: collectedRelations };
  }

  async findPath(sourceId: string, targetId: string): Promise<Entity[]> {
    // BFS 最短路径
    const visited = new Set<string>();
    const parent = new Map<string, string | null>();
    const queue: string[] = [sourceId];

    visited.add(sourceId);
    parent.set(sourceId, null);

    while (queue.length > 0) {
      const current = queue.shift()!;

      if (current === targetId) {
        // 回溯路径
        return this.reconstructPath(parent, targetId);
      }

      // 遍历所有邻居（出边 + 入边）
      const outEdges = this.outgoingEdges.get(current) ?? [];
      const inEdges = this.incomingEdges.get(current) ?? [];

      for (const edge of [...outEdges, ...inEdges]) {
        const neighborId =
          edge.source === current ? edge.target : edge.source;

        if (visited.has(neighborId)) continue;
        if (!this.entities.has(neighborId)) continue;

        visited.add(neighborId);
        parent.set(neighborId, current);
        queue.push(neighborId);
      }
    }

    // 未找到路径
    return [];
  }

  async query(queryText: string): Promise<GraphQueryResult> {
    // 简单的关键词匹配实现
    // 生产环境应接入 LLM 做自然语言理解
    const keywords = queryText.toLowerCase().split(/\s+/);
    const matchedEntities: Entity[] = [];
    const matchedRelations: Relation[] = [];

    for (const entity of this.entities.values()) {
      const nameMatch = keywords.some((kw) =>
        entity.name.toLowerCase().includes(kw),
      );
      const typeMatch = keywords.some((kw) =>
        entity.type.toLowerCase().includes(kw),
      );
      if (nameMatch || typeMatch) {
        matchedEntities.push(entity);
      }
    }

    // 收集匹配实体之间的所有关系
    const matchedEntityIds = new Set(matchedEntities.map((e) => e.id));
    for (const edges of this.outgoingEdges.values()) {
      for (const edge of edges) {
        if (matchedEntityIds.has(edge.source) && matchedEntityIds.has(edge.target)) {
          matchedRelations.push(edge);
        }
      }
    }

    return {
      entities: matchedEntities,
      relations: matchedRelations,
      paths: [],
    };
  }

  /** 回溯 BFS 路径 */
  private reconstructPath(
    parent: Map<string, string | null>,
    targetId: string,
  ): Entity[] {
    const path: Entity[] = [];
    let current: string | null = targetId;

    while (current !== null) {
      const entity = this.entities.get(current);
      if (entity) {
        path.unshift(entity);
      }
      current = parent.get(current) ?? null;
    }

    return path;
  }

  /** 获取存储统计信息 */
  getStats(): { entityCount: number; relationCount: number } {
    let relationCount = 0;
    for (const edges of this.outgoingEdges.values()) {
      relationCount += edges.length;
    }
    return {
      entityCount: this.entities.size,
      relationCount,
    };
  }
}
```

## 四、图检索 (GraphRetriever)

### 4.1 概念说明

GraphRetriever 基于知识图谱进行检索。它从用户问题中识别实体，在图中沿关系链扩展，找到与问题相关的结构化知识，并将其转换为与其他检索器兼容的 SearchResult 格式。

### 4.2 检索方式

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| 实体匹配 | 找到 query 中提到的实体，返回相关子图 | 直接查询实体信息 |
| 多跳查询 | 从实体出发，沿关系链扩展 N 跳 | 多步推理问题 |
| 路径查询 | 找两个实体之间的关系路径 | "A 和 B 是什么关系" |

### 4.3 检索器接口

### 4.4 GraphRetriever 类定义

```typescript
interface GraphRetrieverOptions {
  /** 图存储 */
  graphStore: GraphStore;
  /** LLM 提供者（用于从 query 中提取实体） */
  llmProvider: LLMProvider;
  /** 最大跳数，默认 2 */
  maxHops?: number;
  /** 每跳最大实体数，默认 10 */
  maxEntities?: number;
}

class GraphRetriever implements Retriever {
  private readonly graphStore: GraphStore;
  private readonly llmProvider: LLMProvider;
  private readonly maxHops: number;
  private readonly maxEntities: number;

  constructor(options: GraphRetrieverOptions) {
    this.graphStore = options.graphStore;
    this.llmProvider = options.llmProvider;
    this.maxHops = options.maxHops ?? 2;
    this.maxEntities = options.maxEntities ?? 10;
  }

  async retrieve(
    query: string,
    options?: RetrieveOptions,
  ): Promise<SearchResult[]> {
    const topK = options?.topK ?? 5;

    // 步骤 1：从 query 中提取实体名称
    const entityNames = await this.extractEntitiesFromQuery(query);
    if (entityNames.length === 0) {
      return [];
    }

    // 步骤 2：在图中查找匹配的实体
    const matchedEntities: Entity[] = [];
    for (const name of entityNames) {
      const queryResult = await this.graphStore.query(name);
      matchedEntities.push(...queryResult.entities);
    }

    if (matchedEntities.length === 0) {
      return [];
    }

    // 步骤 3：从匹配实体出发，进行多跳扩展
    const allEntities: Entity[] = [...matchedEntities];
    const allRelations: Relation[] = [];
    const visitedIds = new Set(matchedEntities.map((e) => e.id));

    for (const entity of matchedEntities) {
      const neighborResult = await this.graphStore.getNeighbors(
        entity.id,
        {
          hops: this.maxHops,
          limit: this.maxEntities,
        },
      );

      for (const neighbor of neighborResult.entities) {
        if (!visitedIds.has(neighbor.id)) {
          visitedIds.add(neighbor.id);
          allEntities.push(neighbor);
        }
      }
      allRelations.push(...neighborResult.relations);
    }

    // 步骤 4：将图数据转换为 SearchResult 格式
    const results = this.convertToSearchResults(
      allEntities,
      allRelations,
      query,
    );

    return results.slice(0, topK);
  }

  /** 用 LLM 从 query 中提取实体名称 */
  private async extractEntitiesFromQuery(query: string): Promise<string[]> {
    const response = await this.llmProvider.chat(
      [
        {
          role: 'system',
          content: '你是一个实体识别专家。请从用户的问题中提取所有提到的实体名称。以 JSON 格式返回：{ "entities": ["实体1", "实体2"] }',
        },
        { role: 'user', content: query },
      ],
      { temperature: 0, responseFormat: 'json' },
    );

    const parsed = JSON.parse(response) as { entities: string[] };
    return parsed.entities;
  }

  /**
   * 将图查询结果转换为 SearchResult
   * 每个实体及其关联关系生成一个 SearchResult
   */
  private convertToSearchResults(
    entities: Entity[],
    relations: Relation[],
    query: string,
  ): SearchResult[] {
    const results: SearchResult[] = [];

    // 按实体分组关系
    const entityRelationMap = new Map<string, Relation[]>();
    for (const rel of relations) {
      const rels = entityRelationMap.get(rel.source) ?? [];
      rels.push(rel);
      entityRelationMap.set(rel.source, rels);

      const inRels = entityRelationMap.get(rel.target) ?? [];
      inRels.push(rel);
      entityRelationMap.set(rel.target, inRels);
    }

    for (const entity of entities) {
      const entityRelations = entityRelationMap.get(entity.id) ?? [];

      // 构建结构化文本描述
      const relationDescs = entityRelations.map((r) => {
        if (r.source === entity.id) {
          return `${entity.name} --[${r.type}]--> ${r.target}`;
        } else {
          return `${r.source} --[${r.type}]--> ${entity.name}`;
        }
      });

      const content = [
        `实体：${entity.name}（类型：${entity.type}）`,
        relationDescs.length > 0
          ? `关系：\n${relationDescs.join('\n')}`
          : '',
      ]
        .filter(Boolean)
        .join('\n');

      // 简单的评分：关系越多，信息越丰富，分数越高
      const score = Math.min(1, 0.3 + entityRelations.length * 0.1);

      results.push({
        id: `graph_${entity.id}`,
        content,
        score,
        metadata: {
          source: 'knowledge_graph',
          entityType: entity.type,
          entityName: entity.name,
          relationCount: entityRelations.length,
        },
      });
    }

    // 按分数降序排列
    results.sort((a, b) => b.score - a.score);
    return results;
  }
}
```

## 五、图增强检索 (GraphEnhancedRetriever)

### 5.1 概念说明

GraphEnhancedRetriever 是一个**混合检索器**，同时利用向量检索（语义相似）和图检索（结构化推理）的优势，将两者的结果合并排序后返回。

### 5.2 工作流程

```
用户 Query
    │
    ├──→ 向量检索器 ──→ 语义相关 Chunks ──→ 向量结果
    │
    └──→ 图检索器 ──→ 结构化知识 ──→ 图结果
            │
            │  从 Chunks 中提取实体
            │  在知识图谱中扩展
            │
    合并 + 加权排序 ──→ 最终结果
```

### 5.3 类定义

```typescript
interface GraphEnhancedRetrieverOptions {
  /** 向量检索器 */
  vectorRetriever: Retriever;
  /** 图检索器 */
  graphRetriever: GraphRetriever;
  /** 图存储（用于从 chunk 中提取实体进行图扩展） */
  graphStore: GraphStore;
  /** LLM 提供者 */
  llmProvider: LLMProvider;
  /** 向量结果权重，默认 0.6 */
  vectorWeight?: number;
  /** 图结果权重，默认 0.4 */
  graphWeight?: number;
  /** 最终返回数量 */
  topK?: number;
}

class GraphEnhancedRetriever implements Retriever {
  private readonly vectorRetriever: Retriever;
  private readonly graphRetriever: GraphRetriever;
  private readonly graphStore: GraphStore;
  private readonly llmProvider: LLMProvider;
  private readonly vectorWeight: number;
  private readonly graphWeight: number;
  private readonly topK: number;

  constructor(options: GraphEnhancedRetrieverOptions) {
    this.vectorRetriever = options.vectorRetriever;
    this.graphRetriever = options.graphRetriever;
    this.graphStore = options.graphStore;
    this.llmProvider = options.llmProvider;
    this.vectorWeight = options.vectorWeight ?? 0.6;
    this.graphWeight = options.graphWeight ?? 0.4;
    this.topK = options.topK ?? 5;
  }

  async retrieve(
    query: string,
    options?: RetrieveOptions,
  ): Promise<SearchResult[]> {
    const topK = options?.topK ?? this.topK;

    // 步骤 1：并行执行向量检索和图检索
    const [vectorResults, graphResults] = await Promise.all([
      this.vectorRetriever.retrieve(query, { topK: topK * 2 }),
      this.graphRetriever.retrieve(query, { topK: topK * 2 }),
    ]);

    // 步骤 2：从向量检索结果中提取实体，进行图扩展
    const expandedGraphResults = await this.expandFromVectorResults(
      vectorResults,
    );

    // 步骤 3：合并图检索结果和扩展结果（去重）
    const allGraphResults = this.mergeAndDeduplicate([
      ...graphResults,
      ...expandedGraphResults,
    ]);

    // 步骤 4：加权合并
    const mergedResults = this.mergeResults(
      vectorResults,
      allGraphResults,
    );

    return mergedResults.slice(0, topK);
  }

  /**
   * 从向量检索的 chunk 中提取实体，在知识图谱中扩展
   */
  private async expandFromVectorResults(
    vectorResults: SearchResult[],
  ): Promise<SearchResult[]> {
    const expandedResults: SearchResult[] = [];

    for (const result of vectorResults) {
      // 尝试从 chunk 内容中匹配已知实体
      const queryResult = await this.graphStore.query(result.content);

      for (const entity of queryResult.entities) {
        const neighbors = await this.graphStore.getNeighbors(entity.id, {
          hops: 1,
          limit: 5,
        });

        if (neighbors.entities.length > 0) {
          const content = [
            `实体：${entity.name}（类型：${entity.type}）`,
            `关联实体：${neighbors.entities.map((e) => e.name).join('、')}`,
          ].join('\n');

          expandedResults.push({
            id: `graph_expanded_${entity.id}`,
            content,
            score: result.score * 0.8, // 扩展结果分数略低于原始
            metadata: {
              source: 'graph_expansion',
              sourceChunkId: result.id,
              entityName: entity.name,
            },
          });
        }
      }
    }

    return expandedResults;
  }

  /** 合并并去重结果 */
  private mergeAndDeduplicate(results: SearchResult[]): SearchResult[] {
    const seen = new Set<string>();
    const deduplicated: SearchResult[] = [];

    for (const result of results) {
      if (!seen.has(result.id)) {
        seen.add(result.id);
        deduplicated.push(result);
      }
    }

    return deduplicated;
  }

  /** 加权合并向量结果和图结果 */
  private mergeResults(
    vectorResults: SearchResult[],
    graphResults: SearchResult[],
  ): SearchResult[] {
    const scoreMap = new Map<string, SearchResult>();

    // 归一化向量分数
    const maxVectorScore =
      vectorResults.length > 0
        ? Math.max(...vectorResults.map((r) => r.score))
        : 1;

    for (const result of vectorResults) {
      const normalizedScore =
        (result.score / maxVectorScore) * this.vectorWeight;
      scoreMap.set(result.id, { ...result, score: normalizedScore });
    }

    // 归一化图分数
    const maxGraphScore =
      graphResults.length > 0
        ? Math.max(...graphResults.map((r) => r.score))
        : 1;

    for (const result of graphResults) {
      const normalizedScore =
        (result.score / maxGraphScore) * this.graphWeight;

      const existing = scoreMap.get(result.id);
      if (existing) {
        // 同一结果在两处都出现，分数相加
        existing.score += normalizedScore;
      } else {
        scoreMap.set(result.id, { ...result, score: normalizedScore });
      }
    }

    // 按合并后的分数降序排列
    const merged = Array.from(scoreMap.values());
    merged.sort((a, b) => b.score - a.score);
    return merged;
  }
}
```

## 六、图构建 Pipeline (GraphBuilder)

### 6.1 概念说明

GraphBuilder 提供从文档批量构建知识图谱的完整流水线。它协调实体抽取、去重合并、存储入库等步骤，并生成构建报告。

### 6.2 工作流程

```
文档列表
    │
    ▼
[1] 逐文档实体关系抽取（EntityExtractor）
    │
    ▼
[2] 实体去重与合并（同名实体合并元数据）
    │
    ▼
[3] 关系去重（相同 source + target + type 的关系合并）
    │
    ▼
[4] 批量存入 GraphStore
    │
    ▼
构建报告
```

### 6.3 类定义

```typescript
/** 构建报告 */
interface BuildReport {
  /** 最终实体数量 */
  entityCount: number;
  /** 最终关系数量 */
  relationCount: number;
  /** 处理的文档数量 */
  documentCount: number;
  /** 构建过程中的错误 */
  errors: string[];
  /** 每个文档的抽取统计 */
  perDocument: Array<{
    documentId: string;
    entityCount: number;
    relationCount: number;
    error?: string;
  }>;
  /** 构建耗时（毫秒） */
  durationMs: number;
}

interface GraphBuilderOptions {
  /** 实体关系抽取器 */
  extractor: EntityExtractor;
  /** 图存储 */
  graphStore: GraphStore;
  /** 并发数（同时处理多少文档），默认 3 */
  concurrency?: number;
  /** 单文档超时时间（毫秒），默认 30000 */
  timeoutMs?: number;
}

class GraphBuilder {
  private readonly extractor: EntityExtractor;
  private readonly graphStore: GraphStore;
  private readonly concurrency: number;
  private readonly timeoutMs: number;

  constructor(options: GraphBuilderOptions) {
    this.extractor = options.extractor;
    this.graphStore = options.graphStore;
    this.concurrency = options.concurrency ?? 3;
    this.timeoutMs = options.timeoutMs ?? 30000;
  }

  /**
   * 从文档列表批量构建知识图谱
   * @param documents 文档列表
   * @returns 构建报告
   */
  async buildFromDocuments(documents: Document[]): Promise<BuildReport> {
    const startTime = Date.now();
    const errors: string[] = [];
    const perDocument: BuildReport['perDocument'] = [];

    // 收集所有文档的抽取结果
    const allEntities: Entity[] = [];
    const allRelations: Relation[] = [];

    // 分批并发处理
    for (let i = 0; i < documents.length; i += this.concurrency) {
      const batch = documents.slice(i, i + this.concurrency);

      const batchResults = await Promise.allSettled(
        batch.map((doc) =>
          this.extractWithTimeout(doc),
        ),
      );

      for (let j = 0; j < batch.length; j++) {
        const doc = batch[j];
        const result = batchResults[j];

        if (result.status === 'fulfilled') {
          const graphData = result.value;
          allEntities.push(...graphData.entities);
          allRelations.push(...graphData.relations);
          perDocument.push({
            documentId: doc.id,
            entityCount: graphData.entities.length,
            relationCount: graphData.relations.length,
          });
        } else {
          const errorMsg = `文档 ${doc.id} 抽取失败: ${result.reason}`;
          errors.push(errorMsg);
          perDocument.push({
            documentId: doc.id,
            entityCount: 0,
            relationCount: 0,
            error: errorMsg,
          });
        }
      }
    }

    // 实体去重合并
    const mergedEntities = this.mergeEntities(allEntities);

    // 关系去重
    const mergedRelations = this.deduplicateRelations(allRelations);

    // 存入 GraphStore
    try {
      await this.graphStore.addEntities(mergedEntities);
      await this.graphStore.addRelations(mergedRelations);
    } catch (err) {
      const msg = `存入图存储失败: ${err instanceof Error ? err.message : String(err)}`;
      errors.push(msg);
    }

    return {
      entityCount: mergedEntities.length,
      relationCount: mergedRelations.length,
      documentCount: documents.length,
      errors,
      perDocument,
      durationMs: Date.now() - startTime,
    };
  }

  /** 带超时的抽取 */
  private async extractWithTimeout(doc: Document): Promise<GraphData> {
    return Promise.race([
      this.extractor.extract(doc),
      new Promise<never>((_, reject) =>
        setTimeout(
          () => reject(new Error(`抽取超时（${this.timeoutMs}ms）`)),
          this.timeoutMs,
        ),
      ),
    ]);
  }

  /**
   * 实体去重与合并
   * 同 ID 的实体合并元数据，保留最新的类型信息
   */
  private mergeEntities(entities: Entity[]): Entity[] {
    const entityMap = new Map<string, Entity>();

    for (const entity of entities) {
      const existing = entityMap.get(entity.id);
      if (existing) {
        // 合并元数据
        existing.metadata = {
          ...existing.metadata,
          ...entity.metadata,
        };
      } else {
        entityMap.set(entity.id, { ...entity });
      }
    }

    return Array.from(entityMap.values());
  }

  /**
   * 关系去重
   * 同 source + target + type 的关系视为重复，合并元数据
   */
  private deduplicateRelations(relations: Relation[]): Relation[] {
    const relationMap = new Map<string, Relation>();

    for (const relation of relations) {
      const key = `${relation.source}::${relation.target}::${relation.type}`;
      const existing = relationMap.get(key);
      if (existing) {
        existing.metadata = {
          ...existing.metadata,
          ...relation.metadata,
        };
      } else {
        relationMap.set(key, { ...relation });
      }
    }

    return Array.from(relationMap.values());
  }
}
```
