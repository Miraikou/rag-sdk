# 验收标准

> 本文档为 RAG SDK 各阶段实施提供明确的验收清单与验证方式。每个验收项都包含"验什么"和"怎么验"，用于 vibe coding 时验证 AI 生成的代码是否正确。

---

## 一、阶段验收清单

### Phase 1：基础骨架

**目标：** 搭建最小可用的 RAG Pipeline，完成从文档摄入到查询回答的完整链路。

- [ ] `packages/core/src/types.ts`
  - 包含 `Document` 接口：字段 `id: string`、`content: string`、`metadata: Record<string, unknown>`
  - 包含 `Chunk` 接口：字段 `id`、`documentId`、`content`、`metadata`、`embedding?`、`parentId?`、`children?`、`contextHeader?`
  - 包含 `SearchResult` 接口与 `SearchSource` 类型（`'vector' | 'keyword' | 'graph' | 'fusion'`）
  - 包含 `Citation` 接口：字段 `chunkId`、`documentId`、`content`、`metadata`
  - 包含 `GenerateResult` 接口：字段 `answer`、`sources: Citation[]`、`metadata`
  - 包含 `Message` 接口与 `MessageRole` 类型（`'system' | 'user' | 'assistant'`）
  - 包含 `LLMProvider`、`EmbeddingProvider`、`VectorStore`、`Chunker`、`Retriever`、`QueryTransformer`、`PostProcessor`、`Generator` 接口
  - 包含 `Pipeline` 接口与 `PipelineConfig` 接口
- [ ] `packages/llm/src/openai.ts`
  - 导出 `OpenAILLMProvider` 类，实现 `LLMProvider` 接口
  - `chat(messages: Message[], options?: ChatOptions): Promise<string>` 可正常返回文本
  - `chatStream(messages: Message[], options?: ChatOptions): AsyncIterable<string>` 可逐步产出文本片段
- [ ] `packages/embedding/src/openai.ts`
  - 导出 `OpenAIEmbeddingProvider` 类，实现 `EmbeddingProvider` 接口
  - `embed(text: string): Promise<number[]>` 返回正确维度的向量
  - `embedBatch(texts: string[]): Promise<number[][]>` 返回与输入顺序一致的向量数组
  - `readonly dimension: number` 属性值为 1536（text-embedding-3-small）
- [ ] `packages/storage/src/memory.ts`
  - 导出 `MemoryVectorStore` 类，实现 `VectorStore` 接口
  - `upsert(chunks: Chunk[]): Promise<void>` 写入后可检索
  - `search(query: number[], options?: SearchOptions): Promise<SearchResult[]>` 基于余弦相似度返回排序结果
  - `delete(ids: string[]): Promise<void>` 删除后不可检索
  - `upsertByDocument(documentId, chunks)` 和 `deleteByDocument(documentId)` 按文档粒度操作
- [ ] `packages/document/src/chunking/fixed-size.ts`
  - 导出 `FixedSizeChunker` 类，实现 `Chunker` 接口
  - `chunk(document: Document, options?: ChunkOptions): Chunk[]` 按固定字符数切块
  - 支持 `overlap` 参数，相邻 chunk 有重叠内容
- [ ] `packages/core/src/pipeline.ts`
  - 导出 `RAGPipeline` 类，实现 `Pipeline` 接口
  - `ingest(documents: Document[]): Promise<void>` 串联：切块 → 嵌入 → 存储
  - `query(question: string): Promise<GenerateResult>` 串联：检索 → 生成
  - 构造函数接收 `PipelineConfig`，必填组件缺失时抛出明确错误
- [ ] `packages/indexing/src/indexing-pipeline.ts`
  - 实现 `IndexingPipeline`，串联加载→清洗→去重→元数据→增强→切块→嵌入→存储
  - 支持 `index(documents: Document[])` 方法执行完整索引流程
  - 支持 `reindexDocument(documentId, documents)` 先删旧 chunk 再重新索引
  - 输出 `IndexingReport`，记录各阶段执行结果
- [ ] `packages/indexing/src/types.ts`
  - 定义 `DocumentCleaner` 接口：`clean(documents: Document[]): Promise<Document[]>`
  - 定义 `DocumentDeduplicator` 接口：`deduplicate(documents: Document[]): Promise<Document[]>`
  - 定义 `MetadataExtractor` 接口：`extract(documents: Document[]): Promise<Document[]>`
  - 定义 `DocumentAugmenter` 接口：`augment(chunks: Chunk[]): Promise<Chunk[]>`
  - 定义 `IndexingConfig` 接口：包含各阶段的配置选项
  - 定义 `IndexingReport` 接口：记录各阶段处理数量和耗时
- [ ] 验证：`pnpm run typecheck` 无报错
- [ ] 验证：`pnpm run test:unit` 通过

## 二、模块验收标准

### 1. LLM Provider

**功能验收：**

| 验收项 | 验收标准 | 验证方式 |
|--------|---------|---------|
| `chat()` 基本调用 | 传入 `Message[]`，返回非空 `string` | `packages/llm/__tests__/openai.test.ts` |
| `chat()` 参数传递 | `ChatOptions` 中的 `model`、`temperature`、`maxTokens` 正确传递给底层 API | Mock API 验证请求参数 |
| `chatStream()` 流式输出 | 返回 `AsyncIterable<string>`，可通过 `for await...of` 消费，拼接后与 `chat()` 结果语义一致 | `packages/llm/__tests__/openai.test.ts` |
| 多 Provider 适配 | `OpenAILLMProvider`、`AnthropicLLMProvider`、`GoogleLLMProvider` 均实现 `LLMProvider` 接口 | TypeScript 编译检查 + 各自测试文件 |
| 错误重试 | API 调用失败（如 429/500）时按配置重试，最终抛出包含错误码的异常 | Mock 失败响应验证重试逻辑 |
| Token 统计 | 返回结果的 `metadata` 中包含 `promptTokens`、`completionTokens`、`totalTokens` | 检查 `chat()` 返回的元数据字段 |

**边界条件：**

- 空消息列表：抛出 `Error`，消息为 `"messages must not be empty"` 或类似描述
- 超长输入：不截断，交由底层 API 处理；如超出模型上下文限制，底层 API 报错时原样向上抛出
- 网络失败：重试耗尽后抛出包含原始错误信息的异常
- 无效 API Key：首次调用即抛出认证失败异常，不重试
- `temperature` 超出范围（<0 或 >2）：抛出参数校验异常或由底层 API 报错

### 2. Embedding Provider

**功能验收：**

| 验收项 | 验收标准 | 验证方式 |
|--------|---------|---------|
| `embed()` 基本调用 | 传入非空字符串，返回 `number[]`，长度等于 `dimension` | `packages/embedding/__tests__/openai.test.ts` |
| `embed()` 向量归一化 | 返回向量的 L2 范数接近 1（如适用） | 计算向量范数断言 |
| `embedBatch()` 批量调用 | 传入 `string[]`，返回 `number[][]`，长度与输入一致，顺序对应 | `packages/embedding/__tests__/openai.test.ts` |
| `embedBatch()` 批处理优化 | 大量文本（>100 条）时自动分批请求，不超出 API 单次限制 | Mock 验证请求次数 |
| `dimension` 属性 | 只读属性，值与所用模型匹配（如 `text-embedding-3-small` → 1536） | 断言 `provider.dimension === 1536` |
| 多 Provider 适配 | `OpenAIEmbeddingProvider`、`AnthropicEmbeddingProvider`、`GoogleEmbeddingProvider`、`VoyageEmbeddingProvider` 均实现接口 | TypeScript 编译检查 |

**边界条件：**

- 空字符串输入：`embed("")` 返回零向量或抛出明确异常（取决于底层 API 行为）
- 空数组输入：`embedBatch([])` 返回空数组 `[]`，不发起 API 请求
- 超长文本：超出模型 token 限制时抛出包含错误信息的异常
- 网络失败：重试耗尽后抛出异常
- 批量请求中部分失败：抛出异常，包含失败条目的索引信息

### 3. Vector Store

**功能验收：**

| 验收项 | 验收标准 | 验证方式 |
|--------|---------|---------|
| `upsert()` 写入 | 写入 `Chunk[]`（含 `embedding`）后可通过 `search()` 检索到 | `packages/storage/__tests__/memory.test.ts` |
| `upsert()` 更新 | 对相同 `id` 的 chunk 再次 `upsert`，旧数据被覆盖 | 写入 → 更新 → 检索验证 |
| `search()` 基本检索 | 传入查询向量，返回按余弦相似度降序排列的 `SearchResult[]` | `packages/storage/__tests__/memory.test.ts` |
| `search()` topK 参数 | 返回结果数量不超过 `topK` | 传入 `topK: 3` 验证结果长度 |
| `search()` threshold 参数 | 返回结果的 `score` 均 ≥ `threshold` | 传入 `threshold: 0.8` 验证 |
| `search()` filter 参数 | 返回结果的 `chunk.metadata` 满足过滤条件 | 写入不同 metadata 的 chunk，按 filter 检索 |
| `delete()` 删除 | 删除后对应 chunk 不再出现在检索结果中 | `packages/storage/__tests__/memory.test.ts` |
| `upsertByDocument()` | 按文档 ID 批量写入，旧的同文档数据被替换 | 写入 → 按文档更新 → 验证旧数据消失 |
| `deleteByDocument()` | 按文档 ID 删除其所有 chunk | 写入 → 按文档删除 → 验证无残留 |

**边界条件：**

- 空 `upsert`：`upsert([])` 不报错，不改变存储状态
- 空 `search`：存储为空时 `search()` 返回 `[]`
- 重复 `delete`：删除不存在的 ID 不报错（幂等）
- 维度不匹配：写入的 `embedding` 维度与已有数据不一致时抛出异常
- 超大数据量：10000+ chunks 时 `search()` 仍在合理时间内返回（<500ms）

## 三、接口契约验证

以下列出所有核心接口及其验证方式。每个接口提供 TypeScript 类型检查（编译期）和运行时断言（测试期）两种验证手段。

### 1. LLMProvider

**接口定义：**

```typescript
interface ChatOptions {
  model?: string;
  temperature?: number;
  maxTokens?: number;
  topP?: number;
  stop?: string[];
}

interface LLMProvider {
  chat(messages: Message[], options?: ChatOptions): Promise<string>;
  chatStream(messages: Message[], options?: ChatOptions): AsyncIterable<string>;
}
```

**返回值约束：**

- `chat()` 返回 `Promise<string>`，resolve 值非空
- `chatStream()` 返回 `AsyncIterable<string>`，至少产出 1 个片段
- 两个方法均可能 reject（网络错误、认证失败、速率限制等）

**验证代码示例：**

```typescript
import { describe, it, expect } from 'vitest';
import type { LLMProvider, Message } from '@rag-sdk/core';

function assertLLMProviderContract(provider: LLMProvider) {
  describe('LLMProvider 接口契约', () => {
    const messages: Message[] = [{ role: 'user', content: '你好' }];

    it('chat() 返回 Promise<string>', async () => {
      const result = await provider.chat(messages);
      expect(typeof result).toBe('string');
      expect(result.length).toBeGreaterThan(0);
    });

    it('chat() 支持 ChatOptions 参数', async () => {
      const result = await provider.chat(messages, {
        temperature: 0,
        maxTokens: 50,
      });
      expect(typeof result).toBe('string');
    });

    it('chatStream() 返回 AsyncIterable<string>', async () => {
      const stream = provider.chatStream(messages);

      // 验证 AsyncIterable 协议
      expect(stream[Symbol.asyncIterator]).toBeDefined();

      const chunks: string[] = [];
      for await (const chunk of stream) {
        expect(typeof chunk).toBe('string');
        chunks.push(chunk);
      }
      expect(chunks.length).toBeGreaterThan(0);
    });

    it('空消息列表抛出异常', async () => {
      await expect(provider.chat([])).rejects.toThrow();
    });
  });
}
```

```typescript
}
```

**返回值约束：**

- `upsert()` / `delete()` / `upsertByDocument()` / `deleteByDocument()` 返回 `Promise<void>`
- `search()` 返回 `SearchResult[]`，按 `score` 降序排列，长度 ≤ `topK`

**验证代码示例：**

```typescript
import { describe, it, expect } from 'vitest';
import type { VectorStore, Chunk } from '@rag-sdk/core';

function assertVectorStoreContract(store: VectorStore, dimension: number) {
  describe('VectorStore 接口契约', () => {
    const makeChunk = (id: string, embedding: number[]): Chunk => ({
      id,
      documentId: 'doc-1',
      content: `内容 ${id}`,
      metadata: {},
      embedding,
    });

    it('upsert() 写入后可检索', async () => {
      const vec = Array.from({ length: dimension }, () => Math.random());
      const chunk = makeChunk('c1', vec);
      await store.upsert([chunk]);

      const results = await store.search(vec, { topK: 5 });
      expect(results.length).toBeGreaterThan(0);
      expect(results[0]!.chunk.id).toBe('c1');
    });

    it('search() 结果按 score 降序', async () => {
      const results = await store.search(
        Array.from({ length: dimension }, () => Math.random()),
        { topK: 10 }
      );
      for (let i = 1; i < results.length; i++) {
        expect(results[i]!.score).toBeLessThanOrEqual(results[i - 1]!.score);
      }
    });

    it('search() topK 限制结果数量', async () => {
      const results = await store.search(
        Array.from({ length: dimension }, () => Math.random()),
        { topK: 2 }
      );
      expect(results.length).toBeLessThanOrEqual(2);
    });

    it('delete() 后不再检索到', async () => {
      const vec = Array.from({ length: dimension }, () => Math.random());
      await store.upsert([makeChunk('c-del', vec)]);
      await store.delete(['c-del']);

      const results = await store.search(vec, { topK: 100 });
      const found = results.find((r) => r.chunk.id === 'c-del');
      expect(found).toBeUndefined();
    });

    it('upsertByDocument() 替换同文档旧数据', async () => {
      const old = makeChunk('old-1', Array(dimension).fill(0.1));
      old.documentId = 'doc-x';
      await store.upsert([old]);

      const updated = makeChunk('new-1', Array(dimension).fill(0.9));
      updated.documentId = 'doc-x';
      await store.upsertByDocument('doc-x', [updated]);

      // 旧 chunk 不应再出现
      const results = await store.search(Array(dimension).fill(0.1), { topK: 100 });
      const foundOld = results.find((r) => r.chunk.id === 'old-1');
      expect(foundOld).toBeUndefined();
    });

    it('deleteByDocument() 删除文档所有 chunk', async () => {
      const chunks = [
        makeChunk('d1', Array(dimension).fill(0.5)),
        makeChunk('d2', Array(dimension).fill(0.6)),
      ];
      chunks.forEach((c) => (c.documentId = 'doc-del'));
      await store.upsert(chunks);
      await store.deleteByDocument('doc-del');

      const results = await store.search(Array(dimension).fill(0.5), { topK: 100 });
      const found = results.filter((r) => r.chunk.documentId === 'doc-del');
      expect(found.length).toBe(0);
    });
  });
}
```

### 4. Chunker

**接口定义：**

```typescript
interface ChunkOptions {

  overlap?: number;
  separator?: string;

interface Chunker {
  chunk(document: Document, options?: ChunkOptions): Chunk[];
```

**返回值约束：**

- chunk 的 `content` 非空（除非输入文档内容为空）
- chunk 的 `id` 全局唯一

**验证代码示例：**

```typescript
import { describe, it, expect } from 'vitest';
import type { Chunker, Document } from '@rag-sdk/core';

function assertChunkerContract(chunker: Chunker, name: string) {
  describe(`${name} Chunker 接口契约`, () => {
    const doc: Document = {
      id: 'doc-test',
      content: '这是第一段内容。\n\n这是第二段内容，稍长一些。' +
        '包含多个句子用于测试切块功能。'.repeat(20),
      metadata: { source: 'test' },
    };

    it('返回 Chunk[]，documentId 正确', () => {
      const chunks = chunker.chunk(doc);
      expect(Array.isArray(chunks)).toBe(true);
      chunks.forEach((chunk) => {
        expect(chunk.documentId).toBe('doc-test');
        expect(chunk.id).toBeTruthy();
      });
    });

    it('chunk id 全局唯一', () => {
      const chunks = chunker.chunk(doc);
      const ids = chunks.map((c) => c.id);
      expect(new Set(ids).size).toBe(ids.length);
    });

    it('chunkSize 参数生效', () => {
      const chunks = chunker.chunk(doc, { chunkSize: 20 });
      chunks.forEach((chunk) => {
        // overlap 可能导致略超，但大致不超过 chunkSize
        expect(chunk.content.length).toBeLessThanOrEqual(25);
      });
    });

    it('空文档返回空数组', () => {
      const emptyDoc: Document = { id: 'empty', content: '', metadata: {} };
      const chunks = chunker.chunk(emptyDoc);
      expect(chunks).toEqual([]);
    });
  });
}
```
