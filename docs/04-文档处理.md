# 文档处理模块

> 本文档详细描述 RAG SDK 文档处理模块的完整需求，涵盖文档加载、切块策略、清洗去重、元数据抽取、文档增强和增量更新六大子模块。

---

## 1. 文档加载器 (DocumentLoader)

**概念：** 文档加载器负责将各种格式和来源的原始数据统一转化为 `Document` 对象。它是 RAG Pipeline 的入口，决定了系统能处理哪些数据源。

### 1.1 基类

所有加载器继承自 `BaseLoader`，共享 ID 生成等通用逻辑：

```ts
import { randomUUID } from 'crypto';
import type { Document, DocumentLoader } from './types';

abstract class BaseLoader implements DocumentLoader {
  abstract load(source: string | Buffer): Promise<Document[]>;

  protected generateId(): string {
    return randomUUID();
  }
}
```

### 1.2 TextLoader — 纯文本加载器

**用途：** 加载 `.txt` 纯文本文件，最简单的加载器实现。

```ts
import { readFile } from 'fs/promises';
import { resolve } from 'path';

interface TextLoaderOptions {
  encoding?: BufferEncoding;
}

class TextLoader extends BaseLoader {
  private readonly encoding: BufferEncoding;

  constructor(options?: TextLoaderOptions) {
    super();
    this.encoding = options?.encoding ?? 'utf-8';
  }

  async load(source: string | Buffer): Promise<Document[]> {
    let content: string;
    let filename: string;

    if (Buffer.isBuffer(source)) {
      content = source.toString(this.encoding);
      filename = 'buffer';
    } else {
      const filePath = resolve(source);
      content = await readFile(filePath, { encoding: this.encoding });
      filename = filePath;
    }

    return [
      {
        id: this.generateId(),
        content,
        metadata: {
          source: filename,
          loader: 'TextLoader',
          createdAt: new Date().toISOString(),
        },
      },
    ];
  }
}
```

**关键参数：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `encoding` | `BufferEncoding` | `'utf-8'` | 文件编码 |

**使用示例：**

```ts
const loader = new TextLoader();
const docs = await loader.load('./data/report.txt');
// docs[0].content => 文件完整文本内容
```

### 1.3 MarkdownLoader — Markdown 加载器

**用途：** 加载 Markdown 文件，保留标题层级结构。可选择将整个文件作为单个文档，或按顶级标题拆分为多个文档。

```ts
import { readFile } from 'fs/promises';
import { resolve } from 'path';

interface MarkdownLoaderOptions {
  splitByHeading?: boolean;  // 是否按顶级标题拆分
  headingLevel?: 1 | 2 | 3; // 拆分依据的标题级别（默认 h1）
}

class MarkdownLoader extends BaseLoader {
  private readonly options: Required<MarkdownLoaderOptions>;

  constructor(options?: MarkdownLoaderOptions) {
    super();
    this.options = {
      splitByHeading: options?.splitByHeading ?? false,
      headingLevel: options?.headingLevel ?? 1,
    };
  }

  async load(source: string | Buffer): Promise<Document[]> {
    const content = Buffer.isBuffer(source)
      ? source.toString('utf-8')
      : await readFile(resolve(source), 'utf-8');

    if (!this.options.splitByHeading) {
      return [
        {
          id: this.generateId(),
          content,
          metadata: {
            source: String(source),
            loader: 'MarkdownLoader',
            format: 'markdown',
          },
        },
      ];
    }

    // 按标题级别拆分
    const headingPrefix = '#'.repeat(this.options.headingLevel);
    const sections = this.splitByHeading(content, headingPrefix);

    return sections.map((section) => ({
      id: this.generateId(),
      content: section.content,
      metadata: {
        source: String(source),
        loader: 'MarkdownLoader',
        format: 'markdown',
        heading: section.heading,
        sectionIndex: section.index,
      },
    }));
  }

  private splitByHeading(
    content: string,
    prefix: string
  ): Array<{ content: string; heading: string; index: number }> {
    const regex = new RegExp(`^(${prefix}\\s+.+)$`, 'gm');
    const parts: Array<{ content: string; heading: string; index: number }> = [];
    const segments = content.split(regex);

    let index = 0;
    // segments 交替为正文和标题
    for (let i = 1; i < segments.length; i += 2) {
      const heading = segments[i].trim();
      const body = segments[i + 1] ?? '';
      parts.push({
        content: `${heading}\n${body}`.trim(),
        heading: heading.replace(prefix, '').trim(),
        index: index++,
      });
    }

    // 处理标题前的引导文本（如果有）
    if (segments[0].trim()) {
      parts.unshift({
        content: segments[0].trim(),
        heading: '(preamble)',
        index: 0,
      });
    }

    return parts;
  }
}
```

**关键参数：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `splitByHeading` | `boolean` | `false` | 是否按标题拆分为多个 Document |
| `headingLevel` | `1 \| 2 \| 3` | `1` | 拆分依据的标题级别 |

**使用示例：**

```ts
// 整体加载
const loader = new MarkdownLoader();
const docs = await loader.load('./guide.md');

// 按 h2 拆分
const sectionLoader = new MarkdownLoader({ splitByHeading: true, headingLevel: 2 });
const sections = await sectionLoader.load('./guide.md');
// sections 每个 Document 对应一个二级标题章节
```

### 1.4 PDFLoader — PDF 加载器

**用途：** 加载 PDF 文件，支持按页拆分。依赖 `pdf-parse` 库进行 PDF 解析。

```ts
import { readFile } from 'fs/promises';
import { resolve } from 'path';
import pdfParse from 'pdf-parse';

interface PDFLoaderOptions {
  splitByPage?: boolean; // 是否按页拆分为多个 Document
}

class PDFLoader extends BaseLoader {
  private readonly splitByPage: boolean;

  constructor(options?: PDFLoaderOptions) {
    super();
    this.splitByPage = options?.splitByPage ?? true;
  }

  async load(source: string | Buffer): Promise<Document[]> {
    const buffer = Buffer.isBuffer(source)
      ? source
      : await readFile(resolve(source));

    const pdfData = await pdfParse(buffer);

    if (!this.splitByPage) {
      return [
        {
          id: this.generateId(),
          content: pdfData.text,
          metadata: {
            source: String(source),
            loader: 'PDFLoader',
            format: 'pdf',
            pageCount: pdfData.numpages,
            title: pdfData.info?.Title,
            author: pdfData.info?.Author,
          },
        },
      ];
    }

    // 按分页符拆分（pdf-parse 以 \f 作为分页标记）
    const pages = pdfData.text.split('\f').filter((p) => p.trim());

    return pages.map((pageText, index) => ({
      id: this.generateId(),
      content: pageText.trim(),
      metadata: {
        source: String(source),
        loader: 'PDFLoader',
        format: 'pdf',
        pageNumber: index + 1,
        totalPages: pdfData.numpages,
      },
    }));
  }
}
```

**关键参数：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `splitByPage` | `boolean` | `true` | 是否按页拆分，每页一个 Document |

**外部依赖：** `pdf-parse`

**使用示例：**

```ts
const loader = new PDFLoader({ splitByPage: true });
const pages = await loader.load('./paper.pdf');
// pages[0].metadata.pageNumber => 1
// pages[0].content => 第一页的文本内容
```

### 1.5 JSONLoader — JSON 加载器

**用途：** 加载 JSON 文件，支持通过 `jq` 风格的指针提取嵌套字段。适用于结构化数据（如 API 响应、配置文件）的场景。

```ts
import { readFile } from 'fs/promises';
import { resolve } from 'path';

interface JSONLoaderOptions {
  /** 指定提取的字段路径（如 "data.items"），不指定则使用整个 JSON */
  contentPath?: string;
  /** 指定作为元数据的字段路径列表 */
  metadataPaths?: string[];
}

class JSONLoader extends BaseLoader {
  private readonly options: JSONLoaderOptions;

  constructor(options?: JSONLoaderOptions) {
    super();
    this.options = options ?? {};
  }

  async load(source: string | Buffer): Promise<Document[]> {
    const raw = Buffer.isBuffer(source)
      ? source.toString('utf-8')
      : await readFile(resolve(source), 'utf-8');

    const parsed: unknown = JSON.parse(raw);

    // 提取内容
    const contentTarget = this.options.contentPath
      ? this.getByPath(parsed, this.options.contentPath)
      : parsed;

    // 如果内容是数组，每个元素生成一个 Document
    if (Array.isArray(contentTarget)) {
      return contentTarget.map((item, index) => ({
        id: this.generateId(),
        content: typeof item === 'string' ? item : JSON.stringify(item, null, 2),
        metadata: {
          source: String(source),
          loader: 'JSONLoader',
          format: 'json',
          index,
          ...this.extractMetadata(parsed),
        },
      }));
    }

    return [
      {
        id: this.generateId(),
        content: typeof contentTarget === 'string'
          ? contentTarget
          : JSON.stringify(contentTarget, null, 2),
        metadata: {
          source: String(source),
          loader: 'JSONLoader',
          format: 'json',
          ...this.extractMetadata(parsed),
        },
      },
    ];
  }

  private getByPath(obj: unknown, path: string): unknown {
    return path.split('.').reduce<unknown>((acc, key) => {
      if (acc && typeof acc === 'object' && key in (acc as Record<string, unknown>)) {
        return (acc as Record<string, unknown>)[key];
      }
      return undefined;
    }, obj);
  }

  private extractMetadata(parsed: unknown): Record<string, unknown> {
    if (!this.options.metadataPaths) return {};
    const metadata: Record<string, unknown> = {};
    for (const path of this.options.metadataPaths) {
      const value = this.getByPath(parsed, path);
      if (value !== undefined) {
        metadata[path] = value;
      }
    }
    return metadata;
  }
}
```

**关键参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| `contentPath` | `string` | 提取内容的字段路径（如 `"data.items"`） |
| `metadataPaths` | `string[]` | 提取为元数据的字段路径列表 |

**使用示例：**

```ts
// 加载 API 响应，提取 data.articles 作为内容
const loader = new JSONLoader({
  contentPath: 'data.articles',
  metadataPaths: ['data.totalCount', 'data.lastUpdated'],
});
const docs = await loader.load('./api-response.json');
// 每篇文章生成一个 Document
```

### 1.6 CSVLoader — CSV 加载器

**用途：** 加载 CSV 文件，每行生成一个 Document。适用于表格型数据（如产品目录、FAQ 列表）的场景。

```ts
import { readFile } from 'fs/promises';
import { resolve } from 'path';

interface CSVLoaderOptions {
  delimiter?: string;      // 字段分隔符
  contentColumns?: string[]; // 作为内容的列名（不指定则合并所有列）
  headerRow?: boolean;      // 是否包含表头
}

class CSVLoader extends BaseLoader {
  private readonly options: Required<CSVLoaderOptions>;

  constructor(options?: CSVLoaderOptions) {
    super();
    this.options = {
      delimiter: options?.delimiter ?? ',',
      contentColumns: options?.contentColumns ?? [],
      headerRow: options?.headerRow ?? true,
    };
  }

  async load(source: string | Buffer): Promise<Document[]> {
    const content = Buffer.isBuffer(source)
      ? source.toString('utf-8')
      : await readFile(resolve(source), 'utf-8');

    const lines = content.split('\n').filter((line) => line.trim());
    if (lines.length === 0) return [];

    const headers = this.options.headerRow
      ? this.parseLine(lines[0])
      : this.parseLine(lines[0]).map((_, i) => `col_${i}`);

    const dataLines = this.options.headerRow ? lines.slice(1) : lines;

    return dataLines.map((line, index) => {
      const values = this.parseLine(line);
      const row: Record<string, string> = {};
      headers.forEach((header, i) => {
        row[header] = values[i] ?? '';
      });

      // 拼接内容
      const docContent = this.options.contentColumns.length > 0
        ? this.options.contentColumns.map((col) => row[col] ?? '').join('\n')
        : Object.values(row).join('\n');

      return {
        id: this.generateId(),
        content: docContent.trim(),
        metadata: {
          source: String(source),
          loader: 'CSVLoader',
          format: 'csv',
          rowIndex: index,
          ...row,
        },
      };
    });
  }

  private parseLine(line: string): string[] {
    // 简单 CSV 解析（不处理引号内逗号等复杂情况，生产环境建议使用 csv-parse）
    return line.split(this.options.delimiter).map((v) => v.trim().replace(/^"|"$/g, ''));
  }
}
```

**关键参数：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `delimiter` | `string` | `','` | 字段分隔符 |
| `contentColumns` | `string[]` | `[]` | 作为内容的列名，空则合并所有列 |
| `headerRow` | `boolean` | `true` | 首行是否为表头 |

**使用示例：**

```ts
const loader = new CSVLoader({
  contentColumns: ['question', 'answer'],
});
const docs = await loader.load('./faq.csv');
// 每行 FAQ 生成一个 Document，content 为 question + answer
```

### 1.7 WebLoader — 网页加载器

**用途：** 从 URL 加载网页内容，自动提取正文并去除导航栏、广告等非内容元素。依赖 `cheerio` 进行 HTML 解析。

```ts
import * as cheerio from 'cheerio';

interface WebLoaderOptions {
  /** 提取内容的 CSS 选择器（默认提取 body） */
  selector?: string;
  /** 是否保留图片 alt 文本 */
  includeImageAlt?: boolean;
  /** 请求超时时间（毫秒） */
  timeout?: number;
}

class WebLoader extends BaseLoader {
  private readonly options: Required<WebLoaderOptions>;

  constructor(options?: WebLoaderOptions) {
    super();
    this.options = {
      selector: options?.selector ?? 'body',
      includeImageAlt: options?.includeImageAlt ?? false,
      timeout: options?.timeout ?? 30000,
    };
  }

  async load(source: string | Buffer): Promise<Document[]> {
    if (Buffer.isBuffer(source)) {
      return this.parseHTML(source.toString('utf-8'), 'buffer');
    }

    // source 为 URL
    const controller = new AbortController();
    const timer = setTimeout(() => controller.abort(), this.options.timeout);

    try {
      const response = await fetch(source, { signal: controller.signal });
      if (!response.ok) {
        throw new Error(`HTTP ${response.status}: ${response.statusText}`);
      }
      const html = await response.text();
      return this.parseHTML(html, source);
    } finally {
      clearTimeout(timer);
    }
  }

  private parseHTML(html: string, source: string): Document[] {
    const $ = cheerio.load(html);

    // 移除脚本、样式、导航等非内容元素
    $('script, style, nav, footer, header, aside').remove();

    const title = $('title').text().trim() || $('h1').first().text().trim();
    const element = $(this.options.selector);
    const content = element.text().replace(/\s+/g, ' ').trim();

    const metadata: Record<string, unknown> = {
      source,
      loader: 'WebLoader',
      format: 'html',
      title,
    };

    // 提取 meta 信息
    const description = $('meta[name="description"]').attr('content');
    if (description) metadata.description = description;

    const keywords = $('meta[name="keywords"]').attr('content');
    if (keywords) metadata.keywords = keywords;

    if (this.options.includeImageAlt) {
      const imageAlts = $('img')
        .map((_, el) => $(el).attr('alt'))
        .get()
        .filter(Boolean);
      if (imageAlts.length > 0) metadata.imageAlts = imageAlts;
    }

    return [
      {
        id: this.generateId(),
        content,
        metadata,
      },
    ];
  }
}
```

**关键参数：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `selector` | `string` | `'body'` | 提取正文的 CSS 选择器 |
| `includeImageAlt` | `boolean` | `false` | 是否保留图片 alt 文本 |
| `timeout` | `number` | `30000` | 请求超时（毫秒） |

**外部依赖：** `cheerio`

**使用示例：**

```ts
const loader = new WebLoader({
  selector: 'article',
  includeImageAlt: true,
});
const docs = await loader.load('https://example.com/blog/post');
// docs[0].metadata.title => 文章标题
// docs[0].content => 文章正文文本
```

## 2. 切块策略 (Chunker)

**概念：** 切块策略决定如何将长文档拆分为适合检索和生成的小文本块。切块质量直接影响检索的精确度和生成答案的上下文完整性——块太大则检索噪音多，块太小则上下文断裂。

### 2.1 FixedSizeChunker — 固定大小切块

**概念：** 按固定的字符数（或 token 数）切分文档，相邻块之间可设置重叠区域以保持上下文连续性。这是最基础、最快速的切块策略，适合内容均质性较高的文档。

```ts
interface FixedSizeChunkOptions {
  chunkSize?: number;
  overlap?: number;
  separator?: string;
}

class FixedSizeChunker implements Chunker {
  private readonly chunkSize: number;
  private readonly overlap: number;
  private readonly separator: string;

  constructor(options?: FixedSizeChunkOptions) {
    this.chunkSize = options?.chunkSize ?? 500;
    this.overlap = options?.overlap ?? 50;
    this.separator = options?.separator ?? '\n';
  }

  chunk(document: Document, options?: FixedSizeChunkOptions): Chunk[] {
    const size = options?.chunkSize ?? this.chunkSize;
    const overlap = options?.overlap ?? this.overlap;
    const sep = options?.separator ?? this.separator;

    const text = document.content;
    const chunks: Chunk[] = [];
    let start = 0;
    let index = 0;

    while (start < text.length) {
      let end = Math.min(start + size, text.length);

      // 尝试在分隔符处断开，避免截断句子
      if (end < text.length) {
        const lastSep = text.lastIndexOf(sep, end);
        if (lastSep > start) {
          end = lastSep + sep.length;
        }
      }

      const content = text.slice(start, end).trim();
      if (content) {
        chunks.push({
          id: `${document.id}-chunk-${index}`,
          documentId: document.id,
          content,
          metadata: {
            ...document.metadata,
            chunkIndex: index,
            startOffset: start,
            endOffset: end,
          },
        });
        index++;
      }

      // 下一块的起始位置：考虑 overlap
      start = end - overlap;
      if (start <= 0 && end >= text.length) break;
      if (end >= text.length) break;
    }

    return chunks;
  }
}
```

**关键参数：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `chunkSize` | `number` | `500` | 每块的目标字符数 |
| `overlap` | `number` | `50` | 相邻块的重叠字符数 |
| `separator` | `string` | `'\n'` | 优先断开的分隔符 |

**使用示例：**

```ts
const chunker = new FixedSizeChunker({
  chunkSize: 1000,
  overlap: 100,
  separator: '\n\n',
});

const chunks = chunker.chunk(document);
// chunks 中每个 chunk 约 1000 字符，相邻块有 100 字符重叠
```

### 2.2 RecursiveChunker — 递归切块

**概念：** 先用大块切分，再递归地将大块切分为更小的块，形成层级结构。维护父子关系（`parentId` / `children`），直接支持 Small-to-Big 检索策略——先检索小粒度 chunk 精准匹配，再回溯父 chunk 获取完整上下文。

```ts
interface RecursiveChunkOptions {
  chunkSize?: number;
  overlap?: number;
  separators?: string[];
}

class RecursiveChunker implements Chunker {
  private readonly chunkSize: number;
  private readonly overlap: number;
  private readonly separators: string[];

  constructor(options?: RecursiveChunkOptions) {
    this.chunkSize = options?.chunkSize ?? 500;
    this.overlap = options?.overlap ?? 50;
    this.separators = options?.separators ?? ['\n\n', '\n', '。', '.', ' '];
  }

  chunk(document: Document, options?: RecursiveChunkOptions): Chunk[] {
    const size = options?.chunkSize ?? this.chunkSize;
    const overlap = options?.overlap ?? this.overlap;
    const separators = options?.separators ?? this.separators;

    const allChunks: Chunk[] = [];

    // 第一层：用最大分隔符切分
    const parentChunks = this.splitText(document.content, separators[0], size * 3, overlap);

    parentChunks.forEach((parentText, parentIndex) => {
      const parentId = `${document.id}-parent-${parentIndex}`;

      // 父 chunk
      const parentChunk: Chunk = {
        id: parentId,
        documentId: document.id,
        content: parentText,
        metadata: {
          ...document.metadata,
          level: 0,
          chunkIndex: parentIndex,
        },
        children: [],
      };

      // 第二层：递归用更细粒度的分隔符切分
      const childChunks = this.splitRecursive(parentText, separators.slice(1), size, overlap);

      childChunks.forEach((childText, childIndex) => {
        const childId = `${document.id}-child-${parentIndex}-${childIndex}`;
        parentChunk.children!.push(childId);

        allChunks.push({
          id: childId,
          documentId: document.id,
          content: childText,
          metadata: {
            ...document.metadata,
            level: 1,
            chunkIndex: childIndex,
            parentIndex,
          },
          parentId,
        });
      });

      allChunks.push(parentChunk);
    });

    return allChunks;
  }

  private splitText(text: string, separator: string, size: number, overlap: number): string[] {
    const parts = text.split(separator);
    const chunks: string[] = [];
    let current = '';

    for (const part of parts) {
      if (current.length + part.length + separator.length > size && current) {
        chunks.push(current.trim());
        // overlap：保留上一块的尾部
        const overlapText = current.slice(-overlap);
        current = overlapText + separator + part;
      } else {
        current += (current ? separator : '') + part;
      }
    }

    if (current.trim()) chunks.push(current.trim());
    return chunks;
  }

  private splitRecursive(text: string, separators: string[], size: number, overlap: number): string[] {
    if (text.length <= size) return [text.trim()];
    if (separators.length === 0) {
      // 最终回退：按字符强制切分
      const chunks: string[] = [];
      for (let i = 0; i < text.length; i += size - overlap) {
        chunks.push(text.slice(i, i + size).trim());
      }
      return chunks.filter(Boolean);
    }

    const [currentSep, ...restSeps] = separators;
    const parts = this.splitText(text, currentSep, size, overlap);

    // 如果某些 part 仍然超过 size，用下一个分隔符递归
    return parts.flatMap((part) =>
      part.length > size
        ? this.splitRecursive(part, restSeps, size, overlap)
        : [part]
    );
  }
}
```

**关键参数：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `chunkSize` | `number` | `500` | 子块的目标字符数 |
| `overlap` | `number` | `50` | 相邻块的重叠字符数 |
| `separators` | `string[]` | `['\n\n', '\n', '。', '.', ' ']` | 分隔符优先级列表，按顺序逐级尝试 |

**使用示例：**

```ts
const chunker = new RecursiveChunker({
  chunkSize: 300,
  overlap: 30,
  separators: ['\n\n', '\n', '。', ' '],
});

const chunks = chunker.chunk(document);
// 父 chunk：chunks.filter(c => c.metadata.level === 0)
// 子 chunk：chunks.filter(c => c.metadata.level === 1)
// Small-to-Big：检索到子 chunk 后，通过 parentId 找到父 chunk
```

### 2.3 SemanticChunker — 语义切块

**概念：** 通过计算相邻句子的 Embedding 相似度，在语义断裂处（相似度低于阈值）切分。保证每个 chunk 在语义上自洽，不会把不相关的内容强行放在同一块中。适合内容跨度大、主题多变的长文档。

```ts
interface SemanticChunkOptions {
  similarityThreshold?: number;
  minChunkSize?: number;
  maxChunkSize?: number;
}

class SemanticChunker implements Chunker {
  private readonly embeddingProvider: EmbeddingProvider;
  private readonly similarityThreshold: number;
  private readonly minChunkSize: number;
  private readonly maxChunkSize: number;

  constructor(
    embeddingProvider: EmbeddingProvider,
    options?: SemanticChunkOptions
  ) {
    this.embeddingProvider = embeddingProvider;
    this.similarityThreshold = options?.similarityThreshold ?? 0.5;
    this.minChunkSize = options?.minChunkSize ?? 50;
    this.maxChunkSize = options?.maxChunkSize ?? 1000;
  }

  chunk(document: Document, options?: SemanticChunkOptions): Chunk[] {
    // 注意：语义切块需要异步 Embedding 计算
    // 此处 chunk() 为同步签名，实际使用时应调用 chunkAsync()
    // 这里先进行句子拆分，Embedding 计算延迟到 Pipeline 阶段
    throw new Error(
      'SemanticChunker 需要异步操作，请使用 chunkAsync() 方法'
    );
  }

  async chunkAsync(document: Document, options?: SemanticChunkOptions): Promise<Chunk[]> {
    const threshold = options?.similarityThreshold ?? this.similarityThreshold;
    const minSize = options?.minChunkSize ?? this.minChunkSize;
    const maxSize = options?.maxChunkSize ?? this.maxChunkSize;

    // 1. 拆分句子
    const sentences = this.splitSentences(document.content);
    if (sentences.length === 0) return [];
    if (sentences.length === 1) {
      return [this.createChunk(document, sentences[0], 0)];
    }

    // 2. 计算每句的 Embedding
    const embeddings = await this.embeddingProvider.embedBatch(sentences);

    // 3. 计算相邻句子的余弦相似度，找到断裂点
    const breakPoints: number[] = [];
    for (let i = 0; i < embeddings.length - 1; i++) {
      const similarity = this.cosineSimilarity(embeddings[i], embeddings[i + 1]);
      if (similarity < threshold) {
        breakPoints.push(i + 1);
      }
    }

    // 4. 根据断裂点生成 chunk，并应用 min/max 约束
    const chunks: Chunk[] = [];
    let start = 0;
    let index = 0;

    for (const bp of breakPoints) {
      const chunkText = sentences.slice(start, bp).join(' ');
      if (chunkText.length >= minSize) {
        chunks.push(this.createChunk(document, chunkText, index++));
        start = bp;
      }
      // 如果 chunk 太小，合并到下一块
    }

    // 处理剩余部分
    const remaining = sentences.slice(start).join(' ');
    if (remaining.trim()) {
      // 如果最后一块太小且前面有 chunk，合并到前一块
      if (remaining.length < minSize && chunks.length > 0) {
        chunks[chunks.length - 1].content += ' ' + remaining;
      } else {
        chunks.push(this.createChunk(document, remaining, index));
      }
    }

    // 5. 拆分超过 maxChunkSize 的 chunk
    return this.enforceMaxSize(chunks, maxSize, document);
  }

  private splitSentences(text: string): string[] {
    // 支持中英文句子拆分
    return text
      .split(/(?<=[。！？.!?])\s+/)
      .map((s) => s.trim())
      .filter(Boolean);
  }

  private cosineSimilarity(a: number[], b: number[]): number {
    let dotProduct = 0;
    let normA = 0;
    let normB = 0;
    for (let i = 0; i < a.length; i++) {
      dotProduct += a[i] * b[i];
      normA += a[i] * a[i];
      normB += b[i] * b[i];
    }
    const denominator = Math.sqrt(normA) * Math.sqrt(normB);
    return denominator === 0 ? 0 : dotProduct / denominator;
  }

  private createChunk(document: Document, content: string, index: number): Chunk {
    return {
      id: `${document.id}-semantic-${index}`,
      documentId: document.id,
      content: content.trim(),
      metadata: {
        ...document.metadata,
        chunkIndex: index,
        strategy: 'semantic',
      },
    };
  }

  private enforceMaxSize(chunks: Chunk[], maxSize: number, document: Document): Chunk[] {
    const result: Chunk[] = [];
    for (const chunk of chunks) {
      if (chunk.content.length <= maxSize) {
        result.push(chunk);
      } else {
        // 超长 chunk 按 maxSize 强制拆分
        const text = chunk.content;
        for (let i = 0; i < text.length; i += maxSize) {
          result.push({
            ...chunk,
            id: `${chunk.id}-split-${result.length}`,
            content: text.slice(i, i + maxSize).trim(),
          });
        }
      }
    }
    return result;
  }
}
```

**关键参数：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `similarityThreshold` | `number` | `0.5` | 相邻句子余弦相似度低于此值时断开 |
| `minChunkSize` | `number` | `50` | 最小 chunk 字符数，小于此值会合并到相邻块 |
| `maxChunkSize` | `number` | `1000` | 最大 chunk 字符数，超过此值强制拆分 |

**外部依赖：** `EmbeddingProvider`

**使用示例：**

```ts
const chunker = new SemanticChunker(embeddingProvider, {
  similarityThreshold: 0.6,
  minChunkSize: 100,
  maxChunkSize: 800,
});

const chunks = await chunker.chunkAsync(document);
// 每个 chunk 在语义上自洽，主题一致
```

### 2.4 ContextualHeaderChunker — 上下文头切块

**概念：** 在每个 chunk 前自动添加上下文头（Contextual Chunk Header），包含文档标题、章节信息和上下文摘要。解决独立 chunk 缺少上下文导致检索和生成质量下降的问题——即使 chunk 被单独检索到，LLM 也能通过 Header 理解其所属位置和上下文。

```ts
interface ContextualHeaderOptions {
  headerTemplate?: string;
  includeParentContext?: boolean;
}

class ContextualHeaderChunker implements Chunker {
  private readonly llmProvider: LLMProvider;
  private readonly innerChunker: Chunker;
  private readonly headerTemplate: string;
  private readonly includeParentContext: boolean;

  constructor(
    llmProvider: LLMProvider,
    innerChunker: Chunker,
    options?: ContextualHeaderOptions
  ) {
    this.llmProvider = llmProvider;
    this.innerChunker = innerChunker;
    this.headerTemplate = options?.headerTemplate ??
      '[文档标题: {title}]\n[章节: {section}]\n[上下文摘要: {summary}]\n\n';
    this.includeParentContext = options?.includeParentContext ?? true;
  }

  chunk(document: Document, options?: ChunkOptions): Chunk[] {
    // 同步入口：先用内部 chunker 切块
    const baseChunks = this.innerChunker.chunk(document, options);

    // Header 生成需要异步 LLM 调用，此处只做同步标记
    // 实际 Header 填充通过 addHeaders() 异步完成
    return baseChunks;
  }

  /**
   * 异步方法：为每个 chunk 生成并添加 Contextual Header。
   * Pipeline 摄入阶段应调用此方法而非 chunk()。
   */
  async addHeaders(document: Document, chunks: Chunk[]): Promise<Chunk[]> {
    const title = (document.metadata.title as string) ?? '未命名文档';

    const enhancedChunks: Chunk[] = [];

    for (let i = 0; i < chunks.length; i++) {
      const chunk = chunks[i];

      // 用 LLM 生成上下文摘要
      const summary = await this.generateSummary(chunk, document);

      // 章节信息（如果有）
      const section = (chunk.metadata.heading as string) ??
        (chunk.metadata.section as string) ??
        `第 ${i + 1}/${chunks.length} 块`;

      // 拼装 Header
      const header = this.headerTemplate
        .replace('{title}', title)
        .replace('{section}', section)
        .replace('{summary}', summary);

      enhancedChunks.push({
        ...chunk,
        contextHeader: header,
        content: `${header}${chunk.content}`,
        metadata: {
          ...chunk.metadata,
          hasContextHeader: true,
          headerSummary: summary,
        },
      });
    }

    return enhancedChunks;
  }

  private async generateSummary(chunk: Chunk, document: Document): Promise<string> {
    const prompt: Message[] = [
      {
        role: 'system',
        content: '你是一个文档摘要助手。请用一句话（不超过50字）概括以下文本的核心内容。',
      },
      {
        role: 'user',
        content: this.includeParentContext
          ? `文档标题：${document.metadata.title ?? '未知'}\n\n文本内容：\n${chunk.content.slice(0, 500)}`
          : `文本内容：\n${chunk.content.slice(0, 500)}`,
      },
    ];

    try {
      return await this.llmProvider.chat(prompt, { maxTokens: 100 });
    } catch {
      return '（摘要生成失败）';
    }
  }
}
```

**关键参数：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `headerTemplate` | `string` | 见代码 | Header 模板，支持 `{title}` `{section}` `{summary}` 占位符 |
| `includeParentContext` | `boolean` | `true` | 生成摘要时是否包含文档级上下文 |

**外部依赖：** `LLMProvider`（生成上下文摘要）、内部 `Chunker`（实际切块）

**使用示例：**

```ts
const baseChunker = new FixedSizeChunker({ chunkSize: 500 });
const headerChunker = new ContextualHeaderChunker(llmProvider, baseChunker, {
  headerTemplate: '## {title} > {section}\n> {summary}\n\n',
});

// 1. 先切块
const chunks = headerChunker.chunk(document);

// 2. 再添加上下文头
const enhancedChunks = await headerChunker.addHeaders(document, chunks);
// enhancedChunks[0].content 以 Header 开头，后接原始 chunk 内容
// enhancedChunks[0].contextHeader 单独存储 Header 信息
```

## 3. 去重与清洗

### 3.1 DocumentCleaner — 文档清洗

**概念：** 对文档进行预处理，去除噪音内容（HTML 标签、多余空白、页眉页脚、特殊字符），统一编码格式。清洗后的文档内容更干净，切块和检索的质量更高。

```ts
interface CleanerOptions {
  removeHtml?: boolean;       // 去除 HTML 标签
  removeExtraWhitespace?: boolean; // 合并多余空白
  removeHeaderFooter?: boolean;    // 去除页眉页脚模式
  removeSpecialChars?: boolean;    // 去除特殊字符（可选）
  normalizeEncoding?: boolean;     // 统一 UTF-8 编码
}

class DocumentCleaner {
  private readonly options: Required<CleanerOptions>;

  constructor(options?: CleanerOptions) {
    this.options = {
      removeHtml: options?.removeHtml ?? true,
      removeExtraWhitespace: options?.removeExtraWhitespace ?? true,
      removeHeaderFooter: options?.removeHeaderFooter ?? false,
      removeSpecialChars: options?.removeSpecialChars ?? false,
      normalizeEncoding: options?.normalizeEncoding ?? true,
    };
  }

  clean(document: Document): Document {
    let content = document.content;

    if (this.options.removeHtml) {
      content = this.stripHtml(content);
    }

    if (this.options.removeHeaderFooter) {
      content = this.stripHeaderFooter(content);
    }

    if (this.options.removeSpecialChars) {
      content = this.stripSpecialChars(content);
    }

    if (this.options.removeExtraWhitespace) {
      content = this.normalizeWhitespace(content);
    }

    return {
      ...document,
      content,
      metadata: {
        ...document.metadata,
        cleaned: true,
        cleanedAt: new Date().toISOString(),
      },
    };
  }

  private stripHtml(text: string): string {
    return text
      .replace(/<[^>]+>/g, '')             // 去除 HTML 标签
      .replace(/&nbsp;/g, ' ')             // 转换 HTML 实体
      .replace(/&amp;/g, '&')
      .replace(/&lt;/g, '<')
      .replace(/&gt;/g, '>')
      .replace(/&quot;/g, '"');
  }

  private stripHeaderFooter(text: string): string {
    // 去除每页顶部和底部的重复模式（常见于 PDF 提取的文本）
    const lines = text.split('\n');
    if (lines.length < 10) return text;

    // 检测重复出现的行（页眉页脚通常在多个位置重复）
    const lineFrequency = new Map<string, number>();
    for (const line of lines) {
      const trimmed = line.trim();
      if (trimmed.length > 0 && trimmed.length < 80) {
        lineFrequency.set(trimmed, (lineFrequency.get(trimmed) ?? 0) + 1);
      }
    }

    // 出现次数超过总行数的 10% 且长度较短的行视为页眉页脚
    const threshold = Math.max(3, lines.length * 0.1);
    const headerFooterLines = new Set<string>();
    for (const [line, count] of lineFrequency) {
      if (count >= threshold) {
        headerFooterLines.add(line);
      }
    }

    return lines
      .filter((line) => !headerFooterLines.has(line.trim()))
      .join('\n');
  }

  private stripSpecialChars(text: string): string {
    // 保留中文、英文、数字、基本标点
    return text.replace(/[^一-龥a-zA-Z0-9\s.,;:!?"'()\-\[\]{}。，；：！？""''（）【】]/g, '');
  }

  private normalizeWhitespace(text: string): string {
    return text
      .replace(/[ \t]+/g, ' ')      // 连续空格合并
      .replace(/\n{3,}/g, '\n\n')   // 连续空行合并为双换行
      .trim();
  }
}
```

**关键参数：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `removeHtml` | `boolean` | `true` | 去除 HTML 标签和实体 |
| `removeExtraWhitespace` | `boolean` | `true` | 合并连续空格和空行 |
| `removeHeaderFooter` | `boolean` | `false` | 去除重复出现的页眉页脚 |
| `removeSpecialChars` | `boolean` | `false` | 去除非常规特殊字符 |
| `normalizeEncoding` | `boolean` | `true` | 统一为 UTF-8 |

**使用示例：**

```ts
const cleaner = new DocumentCleaner({
  removeHtml: true,
  removeHeaderFooter: true,
  removeSpecialChars: false,
});

const cleanedDoc = cleaner.clean(rawDocument);
// cleanedDoc.metadata.cleaned => true
```

### 3.2 DocumentDeduplicator — 文档去重

**概念：** 去除重复或高度相似的文档，避免冗余数据污染索引。提供两种去重模式：基于内容 Hash 的精确去重（速度快、零误判）和基于 Embedding 相似度的模糊去重（能捕获内容不同但语义相同的文档）。

```ts
import { createHash } from 'crypto';

interface DeduplicatorOptions {
  mode?: 'hash' | 'embedding' | 'both';
  similarityThreshold?: number;
}

class DocumentDeduplicator {
  private readonly embeddingProvider: EmbeddingProvider | null;
  private readonly mode: 'hash' | 'embedding' | 'both';
  private readonly similarityThreshold: number;

  constructor(
    embeddingProvider?: EmbeddingProvider,
    options?: DeduplicatorOptions
  ) {
    this.embeddingProvider = embeddingProvider ?? null;
    this.mode = options?.mode ?? 'hash';
    this.similarityThreshold = options?.similarityThreshold ?? 0.95;

    if ((this.mode === 'embedding' || this.mode === 'both') && !this.embeddingProvider) {
      throw new Error('embedding 和 both 模式需要提供 EmbeddingProvider');
    }
  }

  async deduplicate(documents: Document[]): Promise<Document[]> {
    let result = documents;

    if (this.mode === 'hash' || this.mode === 'both') {
      result = this.deduplicateByHash(result);
    }

    if (this.mode === 'embedding' || this.mode === 'both') {
      result = await this.deduplicateByEmbedding(result);
    }

    return result;
  }

  private deduplicateByHash(documents: Document[]): Document[] {
    const seen = new Map<string, Document>();

    for (const doc of documents) {
      const hash = this.computeHash(doc.content);
      if (!seen.has(hash)) {
        seen.set(hash, doc);
      }
    }

    return Array.from(seen.values());
  }

  private async deduplicateByEmbedding(documents: Document[]): Promise<Document[]> {
    if (documents.length <= 1 || !this.embeddingProvider) return documents;

    // 批量计算 Embedding
    const embeddings = await this.embeddingProvider.embedBatch(
      documents.map((d) => d.content.slice(0, 2000)) // 截断过长文本
    );

    const keep: boolean[] = new Array(documents.length).fill(true);

    for (let i = 0; i < documents.length; i++) {
      if (!keep[i]) continue;

      for (let j = i + 1; j < documents.length; j++) {
        if (!keep[j]) continue;

        const similarity = this.cosineSimilarity(embeddings[i], embeddings[j]);
        if (similarity >= this.similarityThreshold) {
          // 保留较长的那个
          if (documents[i].content.length >= documents[j].content.length) {
            keep[j] = false;
          } else {
            keep[i] = false;
            break; // i 已被标记删除，跳出内层循环
          }
        }
      }
    }

    return documents.filter((_, i) => keep[i]);
  }

  private computeHash(text: string): string {
    // 去除空白差异后计算 hash，避免仅空格不同的文档逃脱精确去重
    const normalized = text.replace(/\s+/g, ' ').trim();
    return createHash('sha256').update(normalized).digest('hex');
  }

  private cosineSimilarity(a: number[], b: number[]): number {
    let dotProduct = 0;
    let normA = 0;
    let normB = 0;
    for (let i = 0; i < a.length; i++) {
      dotProduct += a[i] * b[i];
      normA += a[i] * a[i];
      normB += b[i] * b[i];
    }
    const denominator = Math.sqrt(normA) * Math.sqrt(normB);
    return denominator === 0 ? 0 : dotProduct / denominator;
  }
}
```

**关键参数：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `mode` | `'hash' \| 'embedding' \| 'both'` | `'hash'` | 去重模式 |
| `similarityThreshold` | `number` | `0.95` | Embedding 模式下判定重复的相似度阈值 |

**使用示例：**

```ts
// 精确去重（快速）
const hashDedup = new DocumentDeduplicator();
const unique1 = await hashDedup.deduplicate(docs);

// 模糊去重（需要 Embedding，能捕获语义重复）
const embeddingDedup = new DocumentDeduplicator(embeddingProvider, {
  mode: 'both',
  similarityThreshold: 0.92,
});
const unique2 = await embeddingDedup.deduplicate(docs);
```

## 4. 元数据抽取 (MetadataExtractor)

**概念：** 自动为文档补充结构化元数据。基础元数据（标题、语言、字数）通过规则提取，高级元数据（主题分类、关键词、摘要）通过 LLM 提取。丰富的元数据能支持 metadata 过滤检索和结果展示。

```ts
interface ExtractionOptions {
  /** 是否使用 LLM 提取高级元数据（主题、关键词、摘要） */
  useLLM?: boolean;
  /** 主题分类的候选类别列表 */
  categories?: string[];
  /** 关键词提取的最大数量 */
  maxKeywords?: number;
}

class MetadataExtractor {
  private readonly llmProvider: LLMProvider | null;

  constructor(llmProvider?: LLMProvider) {
    this.llmProvider = llmProvider ?? null;
  }

  async extract(document: Document, options?: ExtractionOptions): Promise<Document> {
    const useLLM = options?.useLLM ?? false;

    // 基础元数据（规则提取）
    const baseMetadata = this.extractBaseMetadata(document);

    // 高级元数据（LLM 提取）
    let advancedMetadata: Record<string, unknown> = {};
    if (useLLM && this.llmProvider) {
      advancedMetadata = await this.extractAdvancedMetadata(document, options);
    }

    return {
      ...document,
      metadata: {
        ...document.metadata,
        ...baseMetadata,
        ...advancedMetadata,
        extractedAt: new Date().toISOString(),
      },
    };
  }

  private extractBaseMetadata(document: Document): Record<string, unknown> {
    const content = document.content;

    return {
      // 标题提取：取第一个非空行或第一个标题
      title: this.extractTitle(content),
      // 语言检测
      language: this.detectLanguage(content),
      // 字数统计
      charCount: content.length,
      wordCount: this.countWords(content),
      // 行数
      lineCount: content.split('\n').length,
    };
  }

  private extractTitle(content: string): string {
    const lines = content.split('\n');
    for (const line of lines) {
      const trimmed = line.trim();
      if (trimmed.length > 0) {
        // 去除 Markdown 标题前缀
        return trimmed.replace(/^#+\s*/, '');
      }
    }
    return '未命名';
  }

  private detectLanguage(content: string): string {
    // 简单的语言检测：统计中文字符和英文字符的比例
    const chineseChars = (content.match(/[一-龥]/g) ?? []).length;
    const englishChars = (content.match(/[a-zA-Z]/g) ?? []).length;
    const total = chineseChars + englishChars;

    if (total === 0) return 'unknown';
    if (chineseChars / total > 0.3) return 'zh';
    return 'en';
  }

  private countWords(content: string): number {
    // 中文按字计算，英文按词计算
    const chinese = (content.match(/[一-龥]/g) ?? []).length;
    const english = (content.match(/[a-zA-Z]+/g) ?? []).length;
    return chinese + english;
  }

  private async extractAdvancedMetadata(
    document: Document,
    options?: ExtractionOptions
  ): Promise<Record<string, unknown>> {
    const maxKeywords = options?.maxKeywords ?? 5;
    const categories = options?.categories ?? ['技术', '商业', '科学', '教育', '其他'];

    const truncatedContent = document.content.slice(0, 2000);

    const prompt: Message[] = [
      {
        role: 'system',
        content: `你是一个文档分析助手。请分析以下文本并以 JSON 格式返回：
1. topic: 主题分类（从以下类别中选择：${categories.join('、')}）
2. keywords: 关键词列表（最多 ${maxKeywords} 个）
3. summary: 一句话摘要（不超过100字）

请严格返回 JSON，不要包含其他文字。`,
      },
      {
        role: 'user',
        content: truncatedContent,
      },
    ];

    try {
      const response = await this.llmProvider!.chat(prompt, {
        maxTokens: 300,
        temperature: 0,
      });

      const parsed: Record<string, unknown> = JSON.parse(response);
      return {
        topic: parsed.topic,
        keywords: parsed.keywords,
        summary: parsed.summary,
      };
    } catch {
      return {
        topic: '提取失败',
        keywords: [],
        summary: '',
      };
    }
  }
}
```

**关键参数：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `useLLM` | `boolean` | `false` | 是否使用 LLM 提取高级元数据 |
| `categories` | `string[]` | 内置默认 | 主题分类候选列表 |
| `maxKeywords` | `number` | `5` | 最大关键词数量 |

**使用示例：**

```ts
// 仅规则提取（快速、零成本）
const extractor = new MetadataExtractor();
const doc1 = await extractor.extract(document);
// doc1.metadata.language => 'zh'
// doc1.metadata.wordCount => 3200

// 规则 + LLM 提取（更丰富，有 API 成本）
const llmExtractor = new MetadataExtractor(llmProvider);
const doc2 = await llmExtractor.extract(document, {
  useLLM: true,
  categories: ['前端', '后端', '运维', '产品'],
  maxKeywords: 8,
});
// doc2.metadata.topic => '前端'
// doc2.metadata.keywords => ['React', 'TypeScript', ...]
// doc2.metadata.summary => '本文介绍了...'
```

## 5. 文档增强 (DocumentAugmenter)

**概念：** 利用 LLM 为文档生成附加内容（摘要、关键词、QA 对），增强文档的可检索性和信息密度。QA 对增强特别有效——为文档生成可能的提问和回答，使用户的自然语言问题能直接匹配到预生成的 QA 对，显著提升检索命中率。

```ts
interface AugmentOptions {
  generateSummary?: boolean;
  generateKeywords?: boolean;
  generateQA?: boolean;
  qaPairCount?: number;
}

class DocumentAugmenter {
  private readonly llmProvider: LLMProvider;

  constructor(llmProvider: LLMProvider) {
    this.llmProvider = llmProvider;
  }

  async augment(document: Document, options?: AugmentOptions): Promise<Document> {
    const opts: Required<AugmentOptions> = {
      generateSummary: options?.generateSummary ?? true,
      generateKeywords: options?.generateKeywords ?? true,
      generateQA: options?.generateQA ?? false,
      qaPairCount: options?.qaPairCount ?? 3,
    };

    const augmentedMetadata: Record<string, unknown> = {};
    const augmentedParts: string[] = [];

    if (opts.generateSummary) {
      const summary = await this.generateSummary(document);
      augmentedMetadata.summary = summary;
      augmentedParts.push(`[摘要] ${summary}`);
    }

    if (opts.generateKeywords) {
      const keywords = await this.generateKeywords(document);
      augmentedMetadata.keywords = keywords;
      augmentedParts.push(`[关键词] ${keywords.join(', ')}`);
    }

    if (opts.generateQA) {
      const qaPairs = await this.generateQA(document, opts.qaPairCount);
      augmentedMetadata.qaPairs = qaPairs;
      for (const qa of qaPairs) {
        augmentedParts.push(`[Q] ${qa.question}\n[A] ${qa.answer}`);
      }
    }

    // 将增强内容附加到文档末尾（可选：也可以只存 metadata）
    const augmentedContent = document.content + '\n\n---\n' + augmentedParts.join('\n\n');

    return {
      ...document,
      content: augmentedContent,
      metadata: {
        ...document.metadata,
        ...augmentedMetadata,
        augmented: true,
        augmentedAt: new Date().toISOString(),
      },
    };
  }

  private async generateSummary(document: Document): Promise<string> {
    const messages: Message[] = [
      {
        role: 'system',
        content: '请用2-3句话概括以下文本的核心内容，要求简洁准确。',
      },
      { role: 'user', content: document.content.slice(0, 3000) },
    ];

    return this.llmProvider.chat(messages, { maxTokens: 200, temperature: 0 });
  }

  private async generateKeywords(document: Document): Promise<string[]> {
    const messages: Message[] = [
      {
        role: 'system',
        content: '请提取以下文本的5-8个关键词，以 JSON 数组格式返回，如 ["关键词1", "关键词2"]。',
      },
      { role: 'user', content: document.content.slice(0, 2000) },
    ];

    try {
      const response = await this.llmProvider.chat(messages, { maxTokens: 100, temperature: 0 });
      return JSON.parse(response) as string[];
    } catch {
      return [];
    }
  }

  private async generateQA(
    document: Document,
    count: number
  ): Promise<Array<{ question: string; answer: string }>> {
    const messages: Message[] = [
      {
        role: 'system',
        content: `基于以下文本，生成 ${count} 个可能被问到的问题及其答案。
以 JSON 数组格式返回：[{"question": "...", "answer": "..."}]
问题应该自然、具体，答案应该能从文本中直接找到依据。`,
      },
      { role: 'user', content: document.content.slice(0, 3000) },
    ];

    try {
      const response = await this.llmProvider.chat(messages, { maxTokens: 500, temperature: 0.3 });
      return JSON.parse(response) as Array<{ question: string; answer: string }>;
    } catch {
      return [];
    }
  }
}
```

**关键参数：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `generateSummary` | `boolean` | `true` | 是否生成摘要 |
| `generateKeywords` | `boolean` | `true` | 是否生成关键词列表 |
| `generateQA` | `boolean` | `false` | 是否生成 QA 对（成本较高） |
| `qaPairCount` | `number` | `3` | 生成 QA 对的数量 |

**外部依赖：** `LLMProvider`

**使用示例：**

```ts
const augmenter = new DocumentAugmenter(llmProvider);

// 基础增强：摘要 + 关键词
const doc1 = await augmenter.augment(document);

// 完整增强：摘要 + 关键词 + QA 对
const doc2 = await augmenter.augment(document, {
  generateSummary: true,
  generateKeywords: true,
  generateQA: true,
  qaPairCount: 5,
});
// doc2.metadata.qaPairs => [{ question: '...', answer: '...' }, ...]
// doc2.content 末尾附加了增强内容
```

## 6. 增量更新 (IndexManager)

**概念：** 维护文档内容 Hash 记录，在每次摄入时检测文档变更（新增、修改、删除），只处理变化的文档。避免全量重建索引的高昂成本，支持 RAG 系统的持续运维。

```ts
import { createHash } from 'crypto';

interface SyncReport {
  added: number;
  updated: number;
  deleted: number;
  unchanged: number;
}

interface DocumentHashRecord {
  documentId: string;
  hash: string;
  updatedAt: string;
}

interface IndexManagerOptions {
  /** Hash 算法 */
  hashAlgorithm?: string;
}

class IndexManager {
  private readonly store: VectorStore;
  private readonly chunker: Chunker;
  private readonly embeddingProvider: EmbeddingProvider;
  private readonly hashAlgorithm: string;

  /** 内存中的 Hash 记录，生产环境应持久化到数据库 */
  private hashStore: Map<string, DocumentHashRecord>;

  constructor(
    store: VectorStore,
    chunker: Chunker,
    embeddingProvider: EmbeddingProvider,
    options?: IndexManagerOptions
  ) {
    this.store = store;
    this.chunker = chunker;
    this.embeddingProvider = embeddingProvider;
    this.hashAlgorithm = options?.hashAlgorithm ?? 'sha256';
    this.hashStore = new Map();
  }

  /**
   * 同步文档列表到向量存储，只处理变化的文档。
   * @param documents - 当前最新的完整文档列表
   * @returns 同步报告，说明新增、更新、删除、未变的数量
   */
  async sync(documents: Document[]): Promise<SyncReport> {
    const report: SyncReport = { added: 0, updated: 0, deleted: 0, unchanged: 0 };

    // 1. 计算当前文档的 Hash
    const currentHashes = new Map<string, string>();
    for (const doc of documents) {
      const hash = this.computeHash(doc.content);
      currentHashes.set(doc.id, hash);
    }

    // 2. 检测新增和修改
    const docsToProcess: Document[] = [];
    for (const doc of documents) {
      const existing = this.hashStore.get(doc.id);
      const currentHash = currentHashes.get(doc.id)!;

      if (!existing) {
        // 新增
        report.added++;
        docsToProcess.push(doc);
      } else if (existing.hash !== currentHash) {
        // 内容变更
        report.updated++;
        docsToProcess.push(doc);
      } else {
        // 未变化
        report.unchanged++;
      }
    }

    // 3. 检测删除（在 Hash 记录中但不在当前文档列表中）
    const currentIds = new Set(documents.map((d) => d.id));
    const deletedIds: string[] = [];
    for (const [docId] of this.hashStore) {
      if (!currentIds.has(docId)) {
        deletedIds.push(docId);
        report.deleted++;
      }
    }

    // 4. 执行变更

    // 4a. 删除已移除的文档
    for (const docId of deletedIds) {
      await this.store.deleteByDocument(docId);
      this.hashStore.delete(docId);
    }

    // 4b. 处理新增和修改的文档
    for (const doc of docsToProcess) {
      // 如果是更新，先删除旧数据
      if (this.hashStore.has(doc.id)) {
        await this.store.deleteByDocument(doc.id);
      }

      // 切块
      const chunks = this.chunker.chunk(doc);

      // 嵌入
      const texts = chunks.map((c) => c.content);
      const embeddings = await this.embeddingProvider.embedBatch(texts);
      const embeddedChunks = chunks.map((chunk, i) => ({
        ...chunk,
        embedding: embeddings[i],
      }));

      // 写入存储
      await this.store.upsertByDocument(doc.id, embeddedChunks);

      // 更新 Hash 记录
      this.hashStore.set(doc.id, {
        documentId: doc.id,
        hash: currentHashes.get(doc.id)!,
        updatedAt: new Date().toISOString(),
      });
    }

    return report;
  }

  /**
   * 获取当前 Hash 记录的快照（用于持久化或调试）。
   */
  getHashSnapshot(): DocumentHashRecord[] {
    return Array.from(this.hashStore.values());
  }

  /**
   * 从外部恢复 Hash 记录（如从数据库加载）。
   */
  restoreHashRecords(records: DocumentHashRecord[]): void {
    this.hashStore.clear();
    for (const record of records) {
      this.hashStore.set(record.documentId, record);
    }
  }

  private computeHash(content: string): string {
    const normalized = content.replace(/\s+/g, ' ').trim();
    return createHash(this.hashAlgorithm).update(normalized).digest('hex');
  }
}
```

**关键参数：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `hashAlgorithm` | `string` | `'sha256'` | 内容 Hash 算法 |

**使用示例：**

```ts
const indexManager = new IndexManager(vectorStore, chunker, embeddingProvider);

// 首次摄入
const report1 = await indexManager.sync(allDocuments);
// report1 => { added: 50, updated: 0, deleted: 0, unchanged: 0 }

// 修改了 3 篇文档，删除了 2 篇，新增了 5 篇后再次同步
const report2 = await indexManager.sync(updatedDocuments);
// report2 => { added: 5, updated: 3, deleted: 2, unchanged: 45 }

// 持久化 Hash 记录到数据库
const snapshot = indexManager.getHashSnapshot();
await db.save('index-hashes', snapshot);

// 恢复 Hash 记录
const saved = await db.load('index-hashes');
indexManager.restoreHashRecords(saved as DocumentHashRecord[]);
```

VectorStore（写入索引）
